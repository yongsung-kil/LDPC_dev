# 3-8. 프레임 루프의 5-버퍼 복사 memcpy화

| 항목 | 내용 |
|------|------|
| 상태 | **적용 완료** (일괄 진행) |
| 파일 | `1_LDPC_revised/ecc_top.cpp` |
| bit-exact | 보장 |
| 위험 | 낮음 |

## 왜 / 어떻게

프레임마다 5개 배열(HD/SD/CC/CD/inv_cw)을 한 루프에서 원소별 동시 복사 — 5개 스트림 동시 접근으로 캐시 효율이 낮다. 배열별 `memcpy` 5회로 분리 (4곳 일괄 + TV 경로 1곳). 복사 자체는 필요함 — 디코더가 input을 파괴적으로 수정하므로 channel 원본을 보존해야 한다.

## 이식 앵커

"Copy buffer" 주석 또는 `*_input[n] = *_channel[n]` 다중 대입 루프 검색. int 배열 연속 복사이므로 memcpy와 비트 동일.

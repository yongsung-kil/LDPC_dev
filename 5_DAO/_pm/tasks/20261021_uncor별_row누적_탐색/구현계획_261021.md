**Goal:** 기존 LLR matrix로 고쳐지지 않는 uncor를 모은 뒤, uncor 하나마다 그룹 1개 50 iteration 매트릭스를 row 하나씩 쌓아 고치는 매트릭스를 찾는 MPI 도구를 만든다.

**Architecture:** 2_LDPC_base에 seed로 프레임을 재현하는 함수 2개를 더하고(채널, 복호), `5_DAO/RowStack/`에 순수 함수 모듈(매트릭스 규칙, 평가, uncor 파일, 보고)과 MPI 흐름 모듈(RowStack_Main)을 둔다. 흐름 모듈은 병렬 통신과 평가 함수를 주입받아 rank 1개 가짜 평가기로 검사한다.

**Tech Stack:** Python 3.11, numpy 1.26, mpi4py 4.1 (MS-MPI), pytest 9. 디코더는 `2_LDPC_base/src` import (복사 금지). 매트릭스 유효성 검사는 `5_DAO/SRC/DAO_LLR_MATRIX.Is_LLR_Valid`를 검사 코드에서 부른다.

## Global Constraints

- ㉮ `5_DAO/SRC/`의 DAO 소스는 고치지 않는다. `2_LDPC_base/src`는 함수를 더하기만 하고 기존 함수의 동작은 바꾸지 않는다 (설계 5절, 7절 ㉮)
- ㉯ CSW 규칙은 DAO 코드 기준이다: 첫 row -1, 그 뒤 8의 배수, 8-1408, 아래로 갈수록 엄격히 작아진다 (설계 4.3 ㉮㉯). 값은 `DAO_Constants`의 `MIN_CSW`, `STEP_CSW`, `MAX_CSW`를 import해 쓴다
- ㉰ row 값 규칙: 헤더 min/max로 자르고, dv마다 CH 구간과 TH 구간을 각각 내림차순으로 정렬한다 (DAO `Correct_Ch_Th_In_Row`와 같은 결과)
- ㉱ 쌓는 그룹은 1개, 타입 1(CSW 선택), iteration 1-`MAX_ITERATION_OF_STACKED_GROUP`, restart 없음, 분기 표시 -1
- ㉲ 후보 순위: 성공 먼저(성공 iteration이 빠른 쪽), 실패끼리는 최소 잔여 에러 bit 수, 같으면 그때 CSW, 같으면 i*가 빠른 쪽 (설계 4.2 ㉱). rank 사이 동점은 rank 번호가 작은 쪽
- ㉳ 난수: 후보 생성과 변이는 `numpy.random.default_rng([RANDOM_SEED, rank, uncor_idx, attempt, stage, kind_code])`에서만 뽑는다 (설계 4.5 ㉰). 프레임은 `default_rng(int(seed))` (설계 4.6 ㉮)
- ㉴ 파일은 root(rank 0)만 쓴다. 다른 rank는 평가만 한다
- ㉵ 이름은 뜻이 읽히게 길게 짓는다. 주석과 문서는 줄표(em dash, U+2014)와 가운뎃점(middle dot, U+00B7)을 쓰지 않고, 입력 파일은 이름과 치수로만 가리킨다 (루트 CLAUDE.md 문장 작성 규칙)

- ㉷ 검사 입력은 저장소에 든 예시 파일만 쓴다: `2_LDPC_base/Input/H_matrix/example_18x147_z256.qc` (N 37632, 열 차수 2, 3, 4)와 `2_LDPC_base/Input/LLR/LLR_MATRIX_HD_1.txt` (HD, 20 iteration, dv 11, 4, 3, 2). 프레임 1개 20 iteration 복호가 약 0.8초다

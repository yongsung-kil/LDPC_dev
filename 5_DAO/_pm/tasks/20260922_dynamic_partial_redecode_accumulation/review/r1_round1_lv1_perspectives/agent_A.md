- ㉮ Ref-C 는 mode_seed 12 에서 입력 uncor 파일을 "rt" 로 읽고, 실패 시드를 `redecode_uncor_seed_..._{mode_init_seed}.txt` 에 "a" 로 붙인다. mode_init_seed 는 DAO 가 인자 #12 로 넘기는 `self.rank` 다
- ㉯ Ref-C 는 배치 파일이 `cd` 한 자리, 즉 각 rank 의 local_session_dir 에서 실행된다

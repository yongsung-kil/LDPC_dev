## 절 1. Karimi 2013 알고리즘 명세

### 1) 그래프와 기호
- G = (V, E). 단순 그래프(루프와 평행 간선 없음). 이분 그래프는 G = (U 합집합 W, E)이고 U, W는 서로소입니다. 모든 간선이 U와 W 사이를 잇습니다.
- n = |U|, m = |W|. LDPC에서는 U가 변수 노드, W가 검사 노드입니다. n은 부호 길이, m은 패리티 검사식 수입니다.
- H는 Tanner 그래프의 이분 인접 행렬(biadjacency matrix)입니다(각주 1).
- 차수는 d_v입니다. 정규(regular)는 U 노드가 모두 d_u, W 노드가 모두 d_w인 경우이고, 이때 n*d_u = m*d_w = |E|입니다.
- girth g는 최단 사이클 길이입니다. 이분 그래프에서는 짝수입니다.
- 사이클 정의: 이 논문의 "사이클"은 원래 닫힌 보행(closed walk)을 뜻하고, 노드 반복이 허용됩니다. 용어는 아래와 같습니다.
  - backtrackless(되돌아감 없음): 연속한 두 간선이 같지 않음.
  - tailless(꼬리 없음): 첫 간선과 마지막 간선이 다름.
  - tbc walk: tailless backtrackless closed walk.
  - simple: 노드가 모두 서로 다름.
  - 본문에서 "사이클"이라 하면 simple 사이클입니다.
  - N_k는 길이 k인 simple 사이클의 수이고, 시작점만 다른 동치 사이클은 한 번만 셉니다.
- 핵심 사실 Lemma 2: girth g인 그래프에서 길이 2g 미만의 tbc walk는 모두 simple 사이클입니다. 이것이 길이 2g-2까지만 정확한 이유입니다.
  - 문제 구조는 사이클 두 개가 합쳐진 모양입니다. 같은 사이클을 두 번 도는 경우, 두 사이클이 경로로 이어진 경우(Fig. 3의 a, b, c)가 그렇습니다. 이 구조의 최소 길이가 2g입니다.

### 2) 메시지 정의
- 메시지는 단항식(monomial)입니다. 벡터 표현으로는 정수 벡터입니다. 단항식 곱은 벡터 덧셈과 같습니다.
- 시작 노드 u(차수 d_u)의 간선 e_1..e_du로 t=0에 X_1..X_du를 보냅니다. 벡터 표현으로는 길이 d_u의 단위 벡터이고, 예를 들어 d_u=3이면 (1,0,0), (0,1,0), (0,0,1)입니다.
- 그 밖의 모든 노드가 t=0에 보내는 메시지는 1입니다. 벡터 표현으로는 영벡터입니다.
- 이후 모든 메시지도 길이 d_u의 정수 벡터입니다.
- 일정은 병렬 일정(parallel schedule)입니다. U에서 W로 보내고, 이어서 W에서 U로 보냅니다.
- 시각 t=0,1,2,...를 씁니다. 반복 번호 k = t/2 + 1이고, t = 2k-2는 반복 k의 전반(U가 보냄), t = 2k-1은 후반(W가 보냄)입니다.
- t=0은 초기 메시지입니다. 반복 k의 후반에 U가 받는 메시지를 사이클 계수에 씁니다.
- 외인(extrinsic) 규칙: 간선 e로 보내는 메시지는 e로 들어온 메시지에 의존하지 않습니다.

### 3) 갱신 규칙
- U와 W의 규칙이 같습니다. 단항식 곱, 즉 벡터로는 덧셈입니다.
- 식(의사코드 형태):
  - m_out(e) = (그 노드의 모든 입력 간선 e' != e에 대해) 곱 m_in(e')
  - 벡터 표현: m_out(e) = sum_{e' != e} m_in(e')
- 구현 방식(논문 5절 A): 모든 입력 벡터를 한 번 합하고, 간선마다 자기 입력을 뺍니다. 이것이 노드당 (2d-1)*d_u회의 정수 덧셈과 뺄셈입니다.

### 4) 사이클 수 산출
- Lemma 1: 길이 2k 사이클 위의 노드 v가 사이클 쪽 두 간선 e1, e2로 X1, X2를 보냈다면, 반복 k에 그 단항식이 사이클을 한 바퀴 돌아 반대쪽 간선으로 돌아옵니다.
- 추가 복사본(꼬리가 달린 walk 등)을 걸러내려고, 들어온 메시지에서 자기가 보낸 변수를 뺀 "초기 변수 제외" 메시지를 씁니다. 표기는 m^{E,(k)}_{v<-e_j}입니다.
- 식 (1), 두 간선 한 쌍:
  - N^{v}_{2k; e1,e2} = { ex(m^{E,(k)}_{v<-e1}) + ex(m^{E,(k)}_{v<-e2}) } / 2
  - ex(.)는 단항식의 지수합입니다.
- 식 (2), Lemma 4, 노드 v 하나에 대해:
  - N^{v}_{2k} = (1/2) * sum_{j=1..d_v} ex(m^{E,(k)}_{v<-e_j}),  k <= g-1
  - 즉 v의 모든 간선 e_j로 반복 k에 들어온 메시지 각각에서 변수 X_j의 지수를 제외하고 지수합을 구해 모두 더한 뒤 2로 나눕니다.
  - k < g/2이면 v가 받는 메시지는 모두 1이고, 사이클이 없다는 뜻입니다.
- 식 (3), 전체 수:
  - N_2k = (sum_{u in U} N^{u}_{2k}) / k = (sum_{w in W} N^{w}_{2k}) / k,  g/2 <= k <= g-1
  - k로 나누는 이유는 길이 2k 사이클이 U 노드를 k개 지나서 k번 세이기 때문입니다.
- 노드를 처리한 뒤 비활성화(그래프에서 제거)하면 k로 나누는 일이 필요 없습니다. 의사코드가 이 방식이며 마지막에 local-counter/2만 누적합니다.
- 반복 횟수는 k = 1..g-1입니다. 길이 2k의 범위는 2g-2까지입니다.
- 일반(비이분) 그래프에서는 길이 g, g+1, ..., 2g-1을 셀 수 있다고 합니다.
- 예제(Fig. 4, 5): N^{u1}_4 = (1+2+1)/2 = 2, N^{u1}_6 = (2+1+1)/2 = 2.

### 5) 길이 g보다 긴 사이클의 중복 처리
- 별도의 보정식은 없습니다.
- 근거는 Lemma 2와 3입니다. 길이 < 2g인 tbc walk는 모두 simple 사이클입니다. 되돌아감은 외인 규칙이 막고, 꼬리 달린 walk는 "초기 변수 제외" 지수가 제거합니다.
- 두 번 도는 경로와 두 사이클 결합 구조는 길이가 2g 이상이라 범위 밖입니다.
- 따라서 정확한 범위는 2k <= 2g-2입니다.

### 6) 노드별 결과
- 시작 노드 u로 식 (2)를 한 번 돌리면 N^{u}_{2k}를 얻습니다. 이것이 u가 속한 길이 2k 사이클 수입니다.
- 병렬판은 U의 모든 노드를 동시에 초기화합니다(Fig. 6a). 메모리는 더 들고, 노드 비활성화는 못 합니다.
- girth와 N_g 동시 계산(Fig. 6b): 병렬 구현에서 초기 메시지를 노드마다 구분하지 않고 하나의 변수로 둡니다. 비1 메시지를 처음 받는 반복이 k이면 g = 2k이고, N_g = (모든 노드가 받은 비1 메시지 수의 합)/(2k)입니다.
- 이 대목은 문장이 짧아 정확한 구현(카운트를 간선별로 셀지)은 미확인입니다.

### 7) 복잡도와 메모리
- 정규 이분 그래프에서 시작 노드 하나당 반복마다 O(|E|*d_u)이고, g-1회 반복이면 O(g|E|d_u)입니다.
- 전체 복잡도는 O(g*n^2*d_u^2) = O(g|E|^2)입니다.
- 비정규 그래프도 같은 차수입니다.
- 메모리는 간선당 양방향 벡터 두 개입니다. 정규에서 2*d_u*|E| = O(d_u|E|), 비정규에서 O(d_max*|E|)입니다.
- girth를 미리 알아야 합니다. girth를 구하는 데는 O(n^2)가 더 듭니다.
- Halford 2006은 O(g*n^3)이고, n = max(|U|,|W|)입니다.

### 8) Algorithm 1 의사코드 (줄 단위, 원문 순서 그대로, 일부 기호가 깨져 있음)
```
for k = 1 : g-1: counter(k) = 0
for i = 1 : n:
  // Initialization
  l = 1
  for w_j in N(u_i):  m^(0)_{u_i->w_j} = X_l ; l = l+1
  for i' = i+1 : n:   for w_j in N(u_i'):  m^(0)_{u_i'->w_j} = 1
  for k = 1 : g-1:
    // Message passing from W
    for j = 1 : m:
      for u_i' in N(w_j):
        m^(2k-1)_{w_j->u_i'} = (곱) over u_h in N(w_j), h >= i, h != i'  of  m^(2k-2)_{u_h->w_j}
    // Counting cycles
    local-counter(k) = sum over w_j in N(u_i) of ex( m^{E,(2k-1)}_{w_j->u_i} )
    // Message passing from U
    for i' = i+1 : n:
      for w_j in N(u_i'):
        m^(2k)_{u_i'->w_j} = (곱) over w_h in N(u_i'), h != j  of  m^(2k-1)_{w_h->u_i'}
  for k = 1 : g-1: counter(k) = counter(k) + local-counter(k)/2
```
- 첨자(2k-2, 2k-1 등)는 txt에서 깨져 있어 위와 같이 재구성했습니다. 이 재구성은 추정이며, 식 불확실입니다.
- 읽는 요령:
  - 인덱스 i 이하의 U 노드는 이미 비활성화(제거)됩니다.
  - W 노드의 합은 h >= i인 U 노드만 대상이며, 시작 노드 u_i는 포함됩니다.
  - U 쪽 전송은 i' > i인 노드만 합니다. 즉 u_i는 t=0 이후 1만 보냅니다.
  - "초기 변수 제외"는 local-counter에서 j번째 간선의 X_j 지수를 빼는 것입니다.
- 이분 그래프라는 가정 아래 U에서 시작합니다. W에서 시작해도 됩니다.

### 9) 행렬곱 대안 (5절 B)
- 방향 간선 행렬 A_e(Hashimoto 행렬)는 2|E| x 2|E| 행렬입니다.
  - 각 무방향 간선 e_i에 방향 간선 f_i와 f_{|E|+i}를 둡니다.
  - (A_e)_ij = 1이면 f_i가 되돌아감 없이 f_j로 이어진다는 뜻입니다.
  - 따라서 (A_e)_{i, i+|E|} = 0이고 (A_e)_{i+|E|, i} = 0입니다.
- 블록 구조는 A_e = [[A, C],[B, D]]이고, B와 C는 대칭, D = A^T, B와 C의 대각 성분은 0입니다.
- tr(A_e^k)는 길이 k인 tbc walk 수입니다.
- 식 (4): N_k = tr(A_e^k) / (2k),  k < 2g
  - k로 나누는 것은 시작 간선을 바꾼 동치이고, 2로 나누는 것은 두 방향입니다.
- 효율적 구현(식 5, 6):
  - |V| x 2|E| 행렬 B를 만듭니다. A_e에서 각 노드 v에서 나가는 간선들에 해당하는 행을 더하고, 나머지 행은 버립니다.
  - B를 오른쪽에서 A_e로 k-1번 곱합니다. B' = (...((B*A_e)*A_e)...*A_e)
  - B'의 열을 노드별로 묶어 |V| x |V| 행렬 B''를 만듭니다. 그 대각 성분 i번째를 (d_i - 1)로 나눕니다.
  - N_k = tr(B'') / 2k,  k < 2g
  - 복잡도는 O(k*|V|*M)입니다. M은 A_e의 비영 원소 수이고, 정규 부호에서 g <= k <= 2g-2 전체가 O(g|E|^2)입니다. 메모리는 O(|V||E|)로 메시지 전달판보다 큽니다.
- 순진한 방식(A_e^k 전체)은 복잡도 O(g|E|^2 (d_u+d_w)), 메모리 O(|E|^2)입니다.
- A_e의 비영 원소 수는 sum d_u^2 + sum d_w^2 - 2|E|이고, 정규에서 |E|(d_u + d_w - 2)입니다.

## 절 2. Li, Lin 2015 개선 (IMPA, Improved Message-Passing Algorithm)

- 절반 절감의 원리: 사이클 위 u에서 간선 e_j로 출발한 메시지와 e_j'로 출발한 메시지가 같은 사이클을 반대 방향으로 돕니다. 두 메시지는 사이클의 반대편 노드 v_t에 서로 다른 간선으로 도착합니다. u로 돌아올 때까지 기다리지 않고 v_t에서 사이클 존재를 확인합니다. 그래서 길이 2(t+1) 사이클을 t+1 단계(경로 길이 t+1)만에 셉니다.
- 기호 (논문 그대로):
  - 시각 t(0 <= t <= g-2)에 활성인 노드를 v_t라 하고, v_t의 간선을 e^t_1..e^t_{d_vt}로 둡니다.
  - P_{k,j}는 u에서 시작해 u의 k번째 간선과 v_t의 j번째 간선을 지나는 길이 t+1의 경로 집합입니다.
  - (i_{1,j}, ..., i_{du,j})는 v_t가 j번째 간선으로 받은 메시지 벡터이고, 따라서 |P_{k,j}| = i_{k,j}입니다.
- 식 (1), 간선 e_k를 지나는 사이클:
  - N^{(2(t+1))}_{e_k} = sum_{j=1..d_vt} i_{k,j} * sum_{j' > j} sum_{k' = 1..d_u, k' != k} i_{k',j'}
- 식 (2), u와 v_t를 함께 지나는 길이 2(t+1) 사이클:
  - N^{(2(t+1))}_{u,v_t} = sum_{k=1..d_u} sum_{j=1..d_vt} i_{k,j} * sum_{j' > j} sum_{k' != k} i_{k',j'}
  - 논문 원문의 합 범위는 "1 <= k < d_vt, 1 <= j <= d_u" 꼴로 인쇄되어 있어 오타로 보입니다(추정).
- 식 (3): N^{(2(t+1))}_{u} = sum_{v_t} N^{(2(t+1))}_{u,v_t}  (활성 노드 v_t 전체에 대해 합)
- 식 (4): N^{(2(t+1))} = sum_{u in U} N^{(2(t+1))}_{u} / (t+1)  (0 <= t <= g-2)
  - 노드 비활성화 방식을 쓰면 나누기가 필요 없습니다.
- Algorithm 1(IMPA)은 Karimi와 같은 골격입니다. 차이는 아래와 같습니다.
  - t = 1..g-1을 돌며, t가 홀수면 W가 계산하고 짝수면 U가 계산합니다.
  - 각 시각마다 (2), (3)으로 local-counter(t)를 구합니다. 외인 합과 노드 제거 규칙은 Karimi 의사코드와 같습니다.
  - W 합은 h >= i, h != i'이고, U 합은 i' > i의 노드만 대상입니다.
- 시각 표기는 논문 안에서 한 칸 어긋나 보입니다(추정). 본문은 경로 길이를 t+1이라 하는데, 의사코드는 t 시점 계산에 m^{(t-1)}를 읽습니다. 구현할 때는 "도착 노드까지 간선 L개를 지난 경로 수"로 직접 정의하고, 사이클 길이를 2L로 두는 편이 안전합니다.
  - v_t가 u 자신인 경우의 처리는 본문에 명시가 없어 미확인입니다.
- girth는 따로 입력하지 않아도 됩니다. 활성 노드가 서로 다른 두 간선에서 서로 다른 메시지를 처음 받는 시각 t_small을 기록하면 g = 2(t_small + 1)입니다.
- 복잡도는 MPA(Karimi)의 절반입니다.
  - 메모리 위치는 한 벌만 쓰고 제자리 갱신합니다.
  - 필요한 위치 수는 min(d_U, d_W) * E입니다. Karimi는 2*d_u*E였습니다. 여기서 d_U, d_W는 U와 W의 최대 차수입니다.
- 실측: Code II(504x1008, (3,8)) 70.17초 대 139.14초로 약 2배입니다.
- QC-LDPC(quasi-cyclic, 준순환 부호)의 p배 절감(QC-IMPA):
  - H는 J x L 배열이고 블록은 p x p 순환 치환 행렬(CPM) 또는 영행렬(ZM)입니다. n = L*p, m = J*p입니다.
  - 순환 이동 대칭: 사이클 하나가 있으면 같은 모양의 사이클이 p-1개 더 있습니다. ((i0 + l) mod p, (j0 + l) mod p) 꼴로 대응됩니다.
  - U를 L개 부분집합 U^(0)..U^(L-1)로 나눕니다. U^(r)은 H의 열 rp..rp+p-1에 해당합니다. 부분집합마다 한 노드만 시작 노드로 씁니다. 논문의 선택은 u_{1+jp}, 즉 jp번째 열의 노드입니다.
  - 식 (5): N^{(2(t+1))} = sum_{j=0..L-1} p * N^{(2(t+1))}_{u_{1+jp}} / (t+1)
  - 시작 노드 수가 n에서 L = n/p로 줄어 복잡도가 p배 줄어듭니다.
- Algorithm 2(QC-IMPA)는 외곽 루프를 i = 1, 1+p, ..., 1+(L-1)p로 바꾼 것입니다. 논문 txt에서는 그 외 변경점(노드 제거 규칙 폐지 여부)을 확인하지 못했습니다(미확인).
  - 주의(추정): 한 시작 노드만 쓰므로 다른 노드를 제거하는 순차 비활성화를 그대로 쓸 수 없습니다. 이때는 (t+1)로 나누는 식 (5)를 써야 맞습니다.

## 절 3. Dehghan 2020 정리 식

### 기호
- d_v(u): v에서 u까지의 거리. 층 L_i(v): 거리가 i인 노드 집합.
- P_v(u): 부모 집합. d(z) = d(u)-1이고 {z,u}가 간선인 z들.
- C_v(u): 자식 집합. d(z) = d(u)+1인 이웃.
- a_v(u): v에서 u로 가는 최단 경로 수. a_v(u) = sum_{u' in P_v(u)} a_v(u'), a_v(v) = 1  (식 1).
- b_v(u) = sum_{u' in C_v(u)} a_v(u') - a_v(u)  (식 2). 논문 인쇄 상태가 "sum_{u' in C(u)} (a(u') - a(u))" 꼴로 보여 정확한 괄호는 식 불확실입니다. 의미는 자식들의 (a(u') - 1) 합으로 쓰이는 식 (10)과 맞춰 보는 것을 권장합니다.
- 변형 BFS(Algorithm 2): BFS를 두 번 돌립니다. 모두 거리 g/2 + 3까지 진행합니다. 1회차에서 부모, 자식, 층, a(.)를 구합니다. 2회차에서 b(.)를 구합니다.
- 이 장에서는 L(C_i, P_j)가 "사이클 C_i에 경로 P_j를 매단 lollipop"입니다. 꼬리(tail)는 차수 1인 끝 노드, 머리(head)는 차수 3인 노드, 몸통(backbone)은 꼬리의 이웃입니다. L(C_i, P_1)에서는 몸통이 머리입니다.
- "|P|-choose-2"는 원문이 "|P_v(u)| 위 2"로 인쇄한 이항 계수 C(|P_v(u)|, 2)입니다.

### 정리 1
- Lemma 4: 소스 노드 v를 포함하는 g-사이클 수 = sum_{u in L_{g/2}(v)} C(|P_v(u)|, 2)
- Theorem 1:
  - N_g = (2/g) * sum_{v in U} sum_{u in L_{g/2}(v)} C(|P_v(u)|, 2)
  - W에서 합해도 같습니다. 모든 노드에서 합하면 2/g 대신 1/g을 씁니다.

### 정리 2
- v가 머리인 lollipop L(C_g, P_1) 수 = (deg(v) - 2) * sum_{u in L_{g/2}(v)} C(|P_v(u)|, 2)  (식 5)
- Theorem 2: |L(C_g, P_1)| = sum_{v in V} (deg(v) - 2) * sum_{u in L_{g/2}(v)} C(|P_v(u)|, 2)

### 정리 3
- 보조 양 R1, R2:
  - R1(G,v) = (1/2) * sum_{u in L_{g/2+1}(v)} sum_{u1,u2 in P_v(u), u1 != u2} |P_v(u1)| * |P_v(u2)|
    - 간단히 하면 (1/2) * sum_{u in L_{g/2+1}(v)} [ (sum_{u1 in P_v(u)} a(u1))^2 - sum_{u1 in P_v(u)} a(u1)^2 ]  (식 8)
  - R2(G,v) = (1/2) * sum_{u in L_{g/2-1}(v)} sum_{u1,u2 in C_v(u), u1 != u2} (a(u1)-1)(a(u2)-1)
    - 간단히 하면 (1/2) * sum_{u in L_{g/2-1}(v)} [ (b(u))^2 - sum_{u1 in C_v(u)} (a(u1)-1)^2 ]  (식 10)
    - 이때 L_{g/2-1}에서 a(u) = 1임을 씁니다(Corollary 1).
- Lemma 6: v를 지나는 (g+2)-사이클 수 + v가 꼬리인 lollipop L(C_g, P_1) 수 = R1(G,v) + R2(G,v)
- Theorem 3:
  - N_{g+2} = (1/(g+2)) * sum_{v in V} [ R1(G,v) + R2(G,v) - (deg(v) - 2) * sum_{u in L_{g/2}(v)} C(|P_v(u)|, 2) ]

### 정리 4와 6 (g+4 사이클에 필요)
- Theorem 4: |L(C_{g+2}, P_1)| = sum_{v in V} (deg(v) - 2) * [ R1(G,v) + R2(G,v) - sum_{u in L_1(v)} sum_{z in L_{g/2}^{G\{v}}(u)} C(|P_u^{G\{v}}(z)|, 2) ]  (식 13)
  - G\{v}는 v를 제거한 그래프입니다. 소스를 u로 바꿔 다시 BFS를 돌립니다.
- Theorem 6 (girth >= 6): |L(C_g, P_2)| = sum_{v in V} (deg(v) - 1) * sum_{u in L_1(v)} sum_{z in L_{g/2}^{G\{v}}(u)} C(|P_u^{G\{v}}(z)|, 2)  (식 27)
- Theorem 7 (정규, girth >= 6):
  - |L(C_{g+2}, P_1)| = N_{g+2} * ((g+2)/2) * ((d_u - 2) + (d_w - 2))  (식 28)
  - |L(C_g, P_2)| = N_g * (g/2) * ((d_u - 2)(d_w - 1) + (d_w - 2)(d_u - 1))  (식 29)
- Theorem 5 (g+4, girth >= 6): N_{g+4} = (1/(g+4)) * sum_{v} sum_{i=1..5} T_i(G,v) - |L(C_{g+2}, P_1)| - |L(C_g, P_2)|  (식 26)
  - T_1..T_5 (식 15, 16, 21, 24, 25)의 구체 식은 이 보고에서 읽지 않았습니다(미확인).
- 실행 순서: girth를 구한 뒤, 모든 노드를 소스로 변형 BFS를 돌립니다. g+4에는 각 간선 (v,u)에 대해 G\{v}에서 u를 소스로 한 번 더 돌립니다.
- 복잡도: N_g는 O(|V|^2 * Delta)입니다(Delta는 최대 차수).
- 수치 예: 논문의 검산 예제 "4-사이클 36/4 = 9"가 있어 소형 그래프로 구현 검증에 쓸 수 있습니다.

## 절 4. Halford 2006 검증식

txt에서 수식이 심하게 깨져 최종식 중 일부만 신뢰할 수 있습니다.

### 신뢰할 수 있는 부분
- 이분 그래프, E는 |U| x |W| 이분 인접 행렬(e_ij = 1이면 (u_i, w_j) 간선). 행렬 표기:
  - 원소별 곱(Hadamard) C = A o B
  - A[0] 표기: 대각을 0으로 만든 행렬(A 에서 대각 제거)
- 경로 행렬 P^U_k와 P^W_k: 길이 k 경로 수(U 쪽 시작, W 쪽 시작).
- (m, n-m)-lollipop walk: 처음 m개 간선이 경로이고 나머지에서 마지막 노드가 앞의 노드 하나와 같아지는 보행. 길이 2m 사이클은 (0, 2m)-lollipop walk입니다.
- 식 (13): N_2k = (1/k) * Tr(L^U_(0,2k)) / 2 형태로 보입니다. 즉 N_2k = Tr(L^U_(0,2k)) / (2k)로 읽힙니다. 식 불확실입니다. 앞 문장은 "총 사이클 수는 lollipop 행렬의 대각합"이라고 말합니다.
- 식 (11), (12): 사이클이 각 정점을 지나는 수가 L^U_(0,2k)의 대각 성분(= 길이 2k-1 경로 행렬과 E의 원소별 곱에 대각을 취한 것)입니다. 식 불확실입니다.
- lollipop 재귀 (7)-(10): 길이 2k+1 경로 행렬 P^U_{2k+1} = P^U_{2k} E - (lollipop 행렬들의 합)  형태입니다. 초기값 P^U_0 = I, P^W_0 = I로 읽힙니다. 식 불확실입니다.
- 필요한 범위: 2k+1 = g+3까지 풀어야 하고, 0 < n-m < g인 lollipop은 없습니다(girth 제약).
- 복잡도는 O(g*n^3)이고 n = max(|U|, |W|)입니다. 행렬곱 개수에 지배됩니다.

### 신뢰할 수 없는 부분
- 식 (14)-(25), (30)-(38)의 lollipop 행렬 식은 첨자와 계수가 모두 깨졌습니다. "식 불확실"입니다. 이 식을 txt에서 복원해 구현하면 틀릴 가능성이 높습니다.
- 권장 교차검증 수단: (a) Karimi 식 (4)의 tr(A_e^k)/(2k) (소형 H에서 행렬 거듭제곱), (b) 소형 H에 대한 완전 탐색 사이클 열거. 원본 PDF가 필요하면 아카이브에서 pdf 파일을 직접 보십시오.
- 논문에 있는 검증 값(소형 H 두 개): N4 = 452, N6 = 10319, N8 = 199994 (Code A 계열 부호), 다른 소형 부호는 N4 = N6 = N8 = N10 = N14 = 0, N12 = 28, N16 = 21. 이 부호의 H 행렬은 PDF 본문 (39), (40) 식에 있고 txt에서는 복원하지 못했습니다(미확인).

## 절 5. Python 구현 시 주의점

논문에서 직접 언급한 것:
- 정확한 범위는 길이 2g-2까지입니다(Karimi). 그 이상은 두 번 도는 보행이 섞입니다.
- 메시지 연산은 정수 덧셈과 뺄셈뿐입니다(Karimi). 부동소수점이 필요 없고, 정수 자료형을 쓰면 됩니다. 최대값은 사이클 수에 비례해 64비트보다 훨씬 작다고 합니다.
- 합계를 낸 뒤 자기 입력을 빼는 방식이 외인 규칙을 구현하는 방법입니다(Karimi 5절 A).
- 초기 변수 제외: 카운트할 때 시작 노드 u의 j번째 간선으로 돌아온 메시지에서 X_j의 지수를 빼야 합니다(Karimi 식 2).
- 처리가 끝난 시작 노드는 제거합니다. 제거하면 총계를 k로 나눌 필요가 없고 그래프가 점점 작아져 빨라집니다. 병렬판은 이 제거가 불가능합니다(Li, Lin).
- 순차판에서만 노드 제거가 가능합니다. 병렬판은 메모리가 훨씬 많이 듭니다.
- QC 코드는 열 블록마다 대표 노드 하나만 시작하고 p를 곱합니다(Li, Lin 식 5). 노드 제거 규칙과 함께 쓰는 법은 논문에서 확인하지 못했습니다(미확인).
- girth를 미리 알아야 합니다. 계산하려면 병렬판에서 비1 메시지가 처음 나타나는 반복, 또는 IMPA의 t_small을 씁니다.

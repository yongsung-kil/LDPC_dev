# H-matrix 사이클과 trapping set 조사 도구를 위한 논문 선별 (종합)

> 작성: 2026-10-21. 대상 아카이브: 형제 저장소 `LDPC_Paper_Analysis` (메타데이터 22,221편, 본문 txt 6,219편).
> 방법: 키워드로 후보 1,565편을 뽑은 뒤 Sonnet 에이전트 4개가 병렬로 선별 (A 사이클 세기 825편, B trapping set 열거 592편, C 실패 진단 386편, D 웹 인용 수와 공개 구현체 교차 확인). 아래 표의 논문 id와 본문 txt 존재는 DB에서 직접 재확인했다.
> 개별 보고서: 같은 폴더의 `조사_A_사이클세기.md`, `조사_B_trapping_set_열거.md`, `조사_C_실패진단.md`, `조사_D_인용수_구현체.md`. 후보 제목 목록: `후보목록/*_titles.txt` (초록 포함 JSONL은 `후보목록/extract.py`로 재생성).

용어
- ㉮ trapping set(TS): 디코더가 갇히는 변수 노드 집합. (a,b)는 오류 변수 노드 a개와 불만족 검사 노드 b개
- ㉯ elementary trapping set(ETS): 유도 부분 그래프의 검사 노드 차수가 1 또는 2뿐인 TS. leafless ETS(LETS)는 차수 1 노드가 잎이 아닌 ETS
- ㉰ absorbing set: 각 변수 노드에서 만족 검사 노드가 불만족 검사 노드보다 많은 TS (bit flipping 류 디코더의 고정점)
- ㉱ stopping set: 이웃 검사 노드가 모두 두 번 이상 연결된 변수 노드 집합 (소거 채널의 실패 구조)
- ㉲ girth: Tanner 그래프의 최단 사이클 길이. ACE(approximate cycle extrinsic message degree): 사이클 밖으로 나가는 간선 수로 사이클의 유해도를 재는 지표
- ㉳ QC-LDPC(quasi-cyclic): 순환 치환 행렬 블록으로 이루어진 H. 본 저장소의 부호 형식

### 진단 절차 초안 (논문의 어느 단계를 이어 붙이는가)

- 1. 실패 샘플 기록: 최대 반복 후 신드롬이 0이 아니면 반복별 (불만족 검사 노드 집합, hard decision)을 보관하고, 불만족 검사 노드 수가 최소인 반복을 고른다 (Kang ieee:5605921)
- 2. 오류 변수 노드 집합 T = 그 반복의 hard decision XOR 송신어. 불만족 검사 노드 집합과 (a,b)를 산출한다 (정의는 Han ieee:9729722, Zhang ieee:5336848)
- 3. 유도 부분 그래프 추출: T와 이웃 검사 노드를 뽑아 차수 1(불만족)과 차수 2(mis-satisfied)를 구분하고 elementary 여부와 absorbing 조건을 검사한다 (Zhang ieee:5336848)
- 4. 사이클 분석: 유도 부분 그래프 안의 최단 사이클과 사이클 공유 구조를 보고, 목표 2b에서 미리 열거한 TS 목록과 대조한다 (Karimi ieee:6259854)
- 5. 진동 판정: 반복별 불만족 검사 노드 수와 |T| 시계열의 주기성으로 안정형과 진동형을 나눈다 (Han ieee:5089505)
- 6. 검증: Kang의 backtracking대로 경계 변수 노드의 LLR을 뒤집어 재디코딩이 성공하는지 확인한다 (송신어 없이도 되는 절차이므로 실측 데이터에도 적용 가능)
- 7. 통계: 실패 N개를 (a,b)와 동형 클래스로 묶어 빈도표를 만든다. 샘플이 모자라면 Cavus나 Cole의 사이클 시드 편향으로 보강한다

## 5. Python 도구 구성 제안

본 저장소의 기존 자산: `2_LDPC_base/src/pcm.py`의 `QCCode.count_cycles4()`가 base matrix 위에서 Fossorier 조건으로 길이 4 사이클 수를 센다. 길이 6 이상 사이클, 노드별 개수, TS 탐색, 실패 진단은 없다.

| 모듈 | 하는 일 | 기반 논문 | 입력 |
|------|--------|----------|------|
| 사이클 조사 | girth, 길이 4/6/8/10 사이클 수, 변수 노드별 사이클 수와 ACE 분포 | Karimi 2013 (ieee:6336765) 메시지 전달을 기본으로, QC 블록 대표 노드만 시작해 p배 절감 (Li, Lin ieee:7282488). 소형 H는 Halford (ieee:1564444)로 교차 검증 | QCCode (base, z) |
| TS 열거 | (a,b) 상한 안의 LETS와 absorbing set 목록, 지배 구조 | Hashemi 2016 (ieee:7575635) 완전 탐색. 빠른 근사는 Karimi 2012 (ieee:6259854) | QCCode, (a_max, b_max) |
| 실패 진단 | 실패 샘플 하나에서 (a,b), 유도 부분 그래프, 사이클, 안정형과 진동형, error path를 뽑고 TS 목록과 대조 | Kang 2011 (ieee:5605921), Han 2022 (ieee:9729722), Zhang 2009 (ieee:5336848) | 디코더의 반복별 hard decision과 신드롬, 송신어 |

- ㉱ quantumgizmos/ldpc, hichamjanati/pyldpc: 디코딩 시뮬레이터. 사이클이나 TS 열거 기능은 확인되지 않음
- 성숙한 Python TS 열거 구현체는 찾지 못했다

## 7. 아카이브에 없는 정본과 미확인 사항

- ㉮ 없음: Richardson, "Error floors of LDPC codes" (Allerton 2003). TS 개념의 원조. 개념 인용만 필요하므로 도구 제작에는 지장 없음
- ㉯ 없음: Cole 2006 CISS 학회판 (arXiv판 cs/0605051은 있음), Cavus 2005 학회판 (2009 저널판은 있음)
- ㉰ 미확인: Python 실측 시간 (모든 논문이 C++ 또는 MATLAB). 순수 Python은 수십 배 느릴 수 있으므로 numpy와 scipy.sparse 벡터화가 전제
- ㉱ 미확인: Hashemi 2016 알고리즘이 QC 대칭을 쓰지 않으므로, 순환 블록 대표만 탐색하고 p배 곱하는 최적화는 직접 설계해야 함
- ㉲ NAND 분야에서 실패 패턴 분류 자체를 다룬 논문은 제목 기준으로 찾지 못함

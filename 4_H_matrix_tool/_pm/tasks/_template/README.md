# tasks/ 폴더 규칙 (삭제 금지)

TODO에 작업을 추가할 때 `_pm/tasks/{작업명}/` 폴더를 만들고 상세 문서를 작성한다.

- ㉮ `_pm/tasks/{작업명}/{작업명}.md`: 메인 태스크 문서 (목적, 배경, 설계, 수정 대상 파일, 안전성 체크리스트, 미결정 사항)
- ㉯ 관련 분석과 메모 파일은 같은 폴더에 추가
- ㉰ TODO 항목에 `상세: _pm/tasks/{작업명}/` 링크 추가
- ㉱ 완료 시 `_pm/done/{YYYYMMDD}_{주제}/`로 이동하고 `DONE.md` 상단에 요약 추가
- ㉲ 비기술적 단순 작업(문서 정리 등)은 tasks 문서 없이 TODO만 등록

이 규칙은 루트 `_pm/`과 각 프로젝트 `_pm/`에 동일하게 적용한다.

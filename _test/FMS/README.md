# FMS Meta 발표 정리: FDP로 QLC 쓰기 효율 높이기

## 목적

FMS(Flash Memory Summit) QLC 세션에서 Meta가 발표한 슬라이드 "Improving QLC write efficiency
using FDP" 를 받아쓰고, 내용을 이해할 수 있게 풀어 쓰고, 관련 공개 자료를 함께 정리한 묶음입니다.

## 배경

QLC 낸드는 용량당 단가가 싸지만 쓰기 대역폭이 매우 좁습니다. 그 좁은 쓰기의 절반가량을 SSD 내부
청소 작업(가비지 컬렉션)이 소모하는 것이 문제였고, Meta는 NVMe 표준 기능인 FDP(flexible data
placement, 유연한 데이터 배치)로 이 손실을 줄이는 실험 결과를 발표했습니다.

## 활용 방법

- 발표 내용만 빠르게 파악하려면 해설 문서의 0절(한 줄 요약)과 6절(결과)을 봅니다
- 용어가 막히면 해설 문서 1절의 용어 사전을 봅니다
- 슬라이드의 수치를 인용하려면 해설 문서 8절의 검토 메모를 먼저 읽습니다. 실험은 QLC가 아니라
  TLC 드라이브로 수행되었습니다
- 표준 자체나 다른 사례의 수치가 필요하면 웹조사 문서와 그 출처 링크를 따라갑니다

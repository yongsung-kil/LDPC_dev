# Project 3: 논문 아이디어 적용

> 스크리닝을 통과한 논문 아이디어를 실물(C++)에 본격 적용하는 프로젝트.
> 착수 시점: `2_LDPC_light`가 외부 H-matrix와 파라미터로 동작하는 것이 확인된 뒤.
> 착수 전에는 아래 아이디어 대장만 운영한다.

---

## 역할 경계

- ㉮ 이 폴더는 아이디어 대장(모든 출처의 아이디어 접수와 상태 추적)과 본격 적용 실험을 담는다
- ㉯ 착수 시 `2_LDPC_light`를 기반으로 받아 시작한다

---

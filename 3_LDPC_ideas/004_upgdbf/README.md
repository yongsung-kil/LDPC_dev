# 004 upgdbf: 전역 최대 탐색 비트 플리핑 (UP-GDBF)

출처: ieee:9902993 (IEEE OJCAS 2022) | 상태: 실패 (dv 혼합 H-matrix에서 전역 최대 비교가 비호환. dv 균일 부호 채택 시 재평가)

## 📌 요약

- **논문 아이디어**:
    - 경판정 비트 플리핑(BF, Bit Flipping)만으로 높은 오류 수까지 복호하는
      **UP-GDBF**(Unified Penalty Gradient Descent Bit Flipping): 비트마다
      에너지(틀렸다는 증거 점수)를 매겨 **전역 최대인 비트만 플립**하고, 난수를
      에너지 가산항으로 통합함
    - 대상은 NAND용 4KB급 QC-LDPC(Quasi-Cyclic Low-Density Parity-Check, 준순환
      저밀도 패리티 검사) 부호
    - 비트마다 **에너지**를 계산:
        - 채널 초기값과 어긋나면 +1
        - 그 비트에 연결된 위반 검사 수만큼 +
        - 직전 iteration에 플립되지 않았으면 +1
        - 난수로 +0 또는 +1
    - iteration마다 전역 최대 에너지 비트를 모두 플립 (두 pass 구조: 최대 탐색 pass,
      플리핑 pass)
    - 난수를 플립 허가 조건(하드 제약)이 아니라 **에너지 가산항(소프트 제약)으로
      통합**한 것이 핵심 변경. 초기 t_active iteration 동안은 난수를 꺼서 결정적으로 돎
    - 추가 하드웨어 기법 **energy-based backtracking**: 플리핑 pass가 플립이 있는
      column block(순환 치환 단위 z개 비트 묶음)만 접근해 cycle을 42% 넘게 절감
- **제안 이유**:
    - 전역 최대 비교는 "가장 틀렸을 법한 비트"부터 고치므로 비트별 문턱 판정보다
      과교정이 적음
    - 난수의 소프트 제약화는 최대보다 1 낮은 비트에게도 플립 기회를 주어 flip
      miss(그 iteration에서 플립되지 못한 에러 비트)를 줄임
    - 직전 플립 비트의 에너지를 상대적으로 1 낮춰 연속 재플립 진동을 억제함 (momentum)
- **성공시 효과**:
    - 논문 보고는 **EBC(Error Bit Count, 프레임당 고정 에러 수) 138까지 경판정 BF
      단독 복호**
    - 재현되면 평가 영역(프레임당 에러 0-150bit)의 대부분을 1bit 연산으로 끝내
      min-sum(검사식 최솟값 기반 연판정 복호) 가동이 줄어듦 (가장 큰 전력 지렛대 후보)
- **개선 확인방법**:
    - EBC별 BF 단독 FER(Frame Error Rate, 프레임 오류율)로 복호 가능 상한 추정
    - flip miss, 과교정, dv(변수 노드 차수)별 플립 분포, 플립 block 수, min-sum 대비
      연산 수 대리 지표 (상세는 아래 평가 계획 표)
- **실험 결과**:
    - **판정: 실패**. 평가 대상 파라미터에서 BF 단독 복호 가능 상한이 프레임당 에러
      <span class="worse">40bit(EBC 40)</span>으로 목표 영역(0-150bit)의 1/4 수준: dv
      혼합 {2, 3, 4, 11} 구조에서 전역 최대 에너지를 dv=11 column이 독점함
    - 논문 보고 EBC 138의 1/3 아래. 원인은 dv 혼합 구조와 전역 최대 비교의 비호환:
      EBC 120 이상에서 <span class="worse">dv=2, 3 column의 플립이 0회</span>
    - 연산 수 대리 지표(1bit:3bit = 1:3)는 전 포인트에서 min-sum 단독 대비
      <span class="worse">1.6-14배 손해</span>
    - 논문 내부 주장(난수 소프트 제약화, momentum, backtracking 절감 47%)은 모두
      <span class="better">방향 재현</span>. 기법 자체는 건전하고 실패는 부호 구조 차이 때문
    - 재평가 조건: dv 균일(또는 준균일) H-matrix를 쓰는 설계

#### 지표별 해석

1. **복호 가능 상한**:
    - FER 0(300프레임) 상한이 EBC 40, FER 50% 교차가 EBC 80 부근
    - 논문 138, 그리고 min-sum의 한계(별도 실험에서 E=370에 FER 7.15e-5)와 비교해
      <span class="worse">커버 영역이 크게 좁음</span>
2. **실패 원인 (dv 쏠림)**:
    - 에너지 상한이 dv+3이라 dv=11 column(42개 block)이 전역 최대를 독점함
    - EBC가 높을수록 dv=2, 3 에러가 플립 기회를 얻지 못해 정체 (결과 3)
    - 논문 부호는 dv 균일 5라 이 문제가 없음
3. **진단판(dvnorm)은 반대 방향으로 쏠림**:
    - 에너지에서 자기 dv를 빼면(위반-만족 기준) 반대로 dv=2 플립이 폭주함 (EBC
      60에서 dv2 플립 844500회, 과교정률 14%)
    - 단순 차수 보정으로는 해결되지 않고 dv별 가중 설계가 따로 필요함
4. **논문 내부 주장은 방향 재현** (<span class="better">기법 자체는 건전함</span>):
    - 난수 소프트 제약화 이득: upgdbf가 pgdbf보다 EBC 60 FER 2.2배 낮음 (flip miss
      28.2 대 29.6)
    - momentum 이득: no_flip_penalty 대비 EBC 60 FER 4.8배 낮음
    - t_active 초반 난수 차단 이득: EBC 40에서 t0만 실패 발생
    - 이식 실패는 부호 구조 차이 때문
5. **backtracking 대리 지표**:
    - 플립 발생 block 수 평균 3.1-4.2개라 플리핑 pass cycle이 145에서 6-7로 줄어,
      iteration당 cycle 290 대비 약 47% 절감 (<span class="better">논문 42% 이상과
      부합</span>)
    - 다만 BF 자체를 채택하지 않으면 쓸 곳이 없음
6. **error floor**: 측정 FER 범위(3.3e-3 분해능)에서 floor 징후와 miscorrection 없음

## ✅ 결론

- **판정: 실패** (평가 대상 파라미터 기준)
- **근거**:
    1. BF 단독 복호 가능 상한이 EBC 40으로 목표 영역(0-150bit)의 1/4 수준 (논문

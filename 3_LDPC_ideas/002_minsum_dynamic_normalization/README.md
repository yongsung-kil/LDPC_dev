# 002 minsum_dynamic_normalization: min1/min2 격차 기반 동적 정규화

출처: ieee:6865103 (IEEE 2014) | 상태: 조건부 유효 (평가 대상 파라미터로 최종 판정 대기)

## 📌 요약

- **논문 아이디어**:
    - min-sum LDPC 디코더의 검사 노드(CNU, Check Node Unit)는 **검사식에 들어온
      메시지 크기의 최솟값(min1)**과 **둘째 최솟값(min2)**을 골라, **정규화
      계수 α**(0 ≤ α ≤ 1의 곱셈 계수)를 곱해 되돌려 줌
    - 논문은 **α를 고정하지 않고 min2 - min1 격차로 매번 선택**:
        - 격차가 크면:
            - min1이 확실히 가장 작음, 신뢰 높음
            - 높은 계수로 감쇠를 줄임
        - 격차가 작으면:
            - min1과 min2가 비슷, 신뢰 낮음
            - 낮은 계수로 감쇠를 키움
    - 추가로 min1과 min2에 서로 다른 상한(P < Q)을 두는 **이중 상한**
      (001_minsum_dual_clip과 같은 구조)을 결합함
- **제안 이유**:
    - 정규화 계수 하나를 고정하면 모든 검사식이 같은 감쇠를 받음
    - 실제로는 **min1이 min2와 확실히 구분되는 검사식**의 메시지가 더 믿을 만함
    - **신뢰에 비례해 감쇠를 조절**하면, 잘못된 확신의 전파는 억제하고 올바른
      정보의 전달력은 유지할 수 있음
    - 논문은 이 조합으로 **비트 폭을 한 단계 줄이면서**(7비트를 6비트로) 성능
      저하 없음을 보임
- **성공시 효과**:
    - 저비트폭 환경에서 무보정 대비 **FER**(Frame Error Rate, 프레임 오류율) 개선
    - 또는 같은 FER를 **더 좁은 비트 폭**으로 달성
    - 구현 비용은 C++ 기준 C2V 재구성부에 비교 1회와 곱셈 1회 수준
- **개선 확인방법**:
    - on/off FER 비교
    - **α_high 선택율** (전체 C2V 메시지 중 격차가 임계를 넘어 α_high가 적용된
      비율. 0이나 1에 붙으면 고정 계수와 같아지므로, 중간 값이어야 동적 선택이
      실제로 작동하는 것)
    - 고정 계수 대조군 대비 이득 여부 (상세는 아래 평가 계획 표)
- **실험 결과**:
    - **판정: 조건부 유효**. 001과 같은 조건(채널 LLR 크기 대비 edge 상한에 여유가
      있을 때만 이득)에서, 이득 조건에서는 <span class="better">001을 넘어섬</span>
    - 이득 조건(균일 ch=8, edge 상한 15)에서 **클리핑+동적 정규화 결합**이 E=300
      FER <span class="better">5.21e-02로 전 조합 최량</span> (클리핑만 1.00, 고정
      정규화만 1.00, 동적만 4.53e-01)
    - 여유가 없는 환경(LLR_MATRIX_HD_1, 비율 복원)에서는 <span class="worse">모든
      보정이 악화</span>
    - 격차 임계 **T는 튜닝 필수**: T가 edge 레벨 간격보다 작으면 무보정으로, 너무
      크면 고정 정규화로 퇴화함 (가이드: T = edge 레벨 간격, α low 0.75, high 1.0)
    - 평가 대상 파라미터로 최종 판정 대기. 사전 지표는 001과 같은 dv별
      `ch / (edge상한 × dv)` 비율

참고) 논문의 셋째 기법(저장하는 min2 값의 비균일 압축, Min2
Compressor/Expander)은 저장 비트 절감용 하드웨어 기법이고 논문 스스로 FER
중립을 목표로 설계했으므로 py 스크리닝 범위에서 제외함 (저장 비용이 쟁점이
되면 후보 4번 ieee:11476755가 구현 참고용).

#### 지표별 해석

평가 계획 표의 항목 순.

1. **무효과 조합 일치**: (7,7,100,100)이 base_run과 E=200/300 모두 수치 완전
   일치. 구현 동등성 검증 통과
2. **고정 대조군과의 분리**:
    - 상한 여유 환경 E=300에서 고정 0.75는 1.00, 동적(T=4)은 4.53e-01
    - 이득의 원천이 "정규화 자체"가 아니라 **"격차 기반 동적 선택"**임이 분리
      확인됨 (<span class="better">논문 Fig.5의 단계 개선 주장 방향 재현</span>)
3. **α_high 선택율**:
    - T가 인접 레벨 격차 이하이면 선택율이 0.99로 쏠려 <span class="worse">동적
      구조가 무보정으로 퇴화함</span>
    - 원인은 본체(그리고 하드웨어)의 **min2=RESET 승격 근사**: min1이 교체될 때
      min2를 실제 둘째 최솟값이 아니라 최대값(RESET)으로 올려 두므로 격차가
      과대평가됨
    - T를 "두 레벨 이상 차이"로 잡아야(레벨 간격 4에서 T=4) 신호가 살아남
4. **선택율과 α low의 상호 영향**:
    - 같은 T=4에서도 α low가 0.85면 선택율 0.983, 0.75면 0.321
    - 감쇠가 포화 분포 자체를 바꾸므로 선택율은 파라미터와 함께 움직임
    - 0.85는 포화 실패 루프를 끊지 못해 무보정과 같은 결과가 됨 (문턱 효과)
5. **수렴 속도**:
    - E=200 복구 조합의 avg_iter는 클리핑만 3.8, 클리핑+동적 4.3, 동적만 6.4,
      고정만 6.4
    - 클리핑이 수렴을 주도하고 동적 정규화는 E=300의 실패 프레임을 추가로 살림

## ✅ 결론

- **판정: 조건부 유효**
- **근거**: 001과 같은 조건 구조(채널 LLR 크기 대비 **edge 상한의 여유**가 있을
  때만 이득)에, 이득 조건에서는 <span class="better">001을 넘어섬</span>
    1. 이득 조건(상한 여유 환경)에서 **클리핑+동적 정규화 결합**이 E=300 FER
       5.21e-02로 전 조합 최량. 클리핑만(1.00), 고정 정규화만(1.00), 동적만(4.53e-01)을
       전부 큰 폭으로 이김. 논문의 결합 주장이 방향 그대로 재현됨
    2. 동적 선택의 격차 임계 **T는 튜닝 필수**: min2=RESET 승격 근사 때문에
       T < 레벨 간격이면 무보정으로, T가 너무 크면 고정 정규화로 퇴화함.
       가이드: **T = edge 레벨 간격** (두 레벨 이상 차이일 때만 α_high)
    3. α 가이드: **low 0.75, high 1.0**. low 0.85는 문턱을 못 넘고 0.5는 과함
    4. 여유가 없는 환경(LLR_MATRIX_HD_1, 비율 복원)에서는 001과 마찬가지로 손해
- **판정 사전 지표**: 001과 공유. 평가할 LLR set의 dv별 `ch / (edge상한 × dv)`
  비율이 1에 가까우면 여지 없음

## ⏭ 후속

- 평가 대상 파라미터로 config_target.json 스캔을 돌려 최종 판정
  (001과 같은 선행 조건. 판정 순서: 사전 지표, 무효과 기준선, 7,7,75,100,2 근방
  스캔. 3-bit 레벨 {7,5,3,1}이면 레벨 간격 2라 T=2)
- 유효 시 001 클리핑과의 결합이 기본형 (이 실험의 최량 조합)

아이디어 실험을 수행하면 결과와 인사이트를 반드시 여기에 기록한다 (최신이 위). 각 항목에 실험 환경(H-matrix, LLR set, edge 양자화, 채널, seed)을 함께 적어, 나중에 "어떤 환경에서 얻은 인사이트인지"를 재현 가능하게 남긴다.

  • 인사이트:
  • ㉮ 격차 임계 T는 본체의 min2=RESET 승격 근사 때문에 튜닝이 급소다: min1 교체 시 min2가 실제 둘째 최솟값이 아니라 RESET으로 올라가 격차가 과대평가되므로, T가 인접 레벨 격차 이하이면 알파 high 선택율이 0.99로 쏠려 무보정으로 퇴화한다. T = edge 레벨 간격(두 레벨 이상 차이)이 가이드
  • ㉯ 이득 조건에서 동적 선택은 고정 정규화를 명확히 이긴다 (상한 여유 환경 E=300: 고정 1.00, 동적 4.53e-01). 이득의 원천이 정규화 자체가 아니라 격차 기반 선택임이 분리 확인됨
  • ㉰ 클리핑(001)과 결합하면 각자 단독보다 크게 낫다 (E=300 5.21e-02): 클리핑이 E=200 수렴을 주도(avg_iter 3.8)하고 동적 정규화가 E=300 실패 프레임을 추가로 살린다. 기본형은 결합형
  • ㉱ 알파 low에 문턱 거동이 있다: 0.75는 포화 붕괴 루프를 끊지만 0.85는 못 끊어 무보정과 같아진다 (감쇠가 포화 분포를 바꿔 선택율 자체가 되먹임: 같은 T=4에서 0.75면 선택율 0.321, 0.85면 0.983). 0.5는 과감쇠로 손해
  • ㉲ 조건 구조는 001과 동일: ch 대비 edge 상한 여유가 없으면(원본 LLR, 비율 복원 환경) 어떤 정규화도 손해. 사전 지표 ch / (edge상한 × dv) 공유
  • 상세: 002_minsum_dynamic_normalization/README.md, 재현은 scan.py + config_headroom.json (조합 표기 P,Q,알파low%,알파high%,격차T)

  • 환경: H-matrix example_18x147_z256.qc (base 18x147, z=256, col degree {2:17, 3:1, 4:129}), seed 0, fixed_error [200, 300], frames_per_batch 64, max_iter 20. LLR set과 edge 양자화는 아래 세 조합

환경 LLR set edge 상한 무클립 기준선 논문 가이드 클립 (P=상한/4, Q=상한/2)

  • 인사이트:
  • ㉮ 클리핑의 득실은 H-matrix 품질이 아니라 채널 LLR 스케일 대비 edge magnitude 상한의 여유(성장 여지)가 결정한다. 여유가 없으면(원본 LLR 환경, 비율 복원 환경) 클리핑은 반전 가능성만 깎아 악화시키고, 여유가 커서 무클립이 과확신으로 붕괴하는 상한 여유 환경에서는 논문 가이드값이 FER 1.0을 0으로 되돌린다
  • ㉯ 사망 경계는 반전 가능 조건으로 정확히 예측된다: dv 열의 최대 extrinsic Q + (dv-1)·P가 그 dv의 ch보다 작으면 해당 열은 채널 결정을 영원히 반전 불능. 관측 전례와 일치 (원본 LLR 환경 dv=4 ch=10: (2,3)은 9로 사망, (2,5)는 11로 생존. 비율 복원 환경 dv=4 ch=16: (4,8)은 16 동률로 사실상 사망)
  • ㉰ 같은 P에서 Q를 키우면 일관 개선: 이중 상한(P<Q)이 단일 상한(P=Q)보다 낫다는 논문 구조 주장은 세 환경 모두에서 방향 재현
  • ㉱ dv=2 열(ch=28, 상한 7×2=14)은 원본 LLR 환경에서 클리핑과 무관하게 처음부터 반전 불능 (전 실행에서 에러 22.7개 동결, TODO의 기지 위반). 성공 판정이 information 구간만 검사하므로 FER에는 직접 안 걸림
  • ㉲ 적용 판단 기준 도출: 평가할 LLR set에서 dv별 ch / (7·dv) 비율을 먼저 보면 클리핑 여지가 있는지 사전 판정 가능. 비율이 1에 가까우면 여지 없음
  • 상세: 001_minsum_dual_clip/README.md, 재현은 scan.py + config_headroom.json, config_balanced.json

# 실험 로그 (아이디어 실험 공통)

> 아이디어 실험을 수행하면 결과와 인사이트를 반드시 여기에 기록한다 (최신이 위).
> 각 항목에 실험 환경(H-matrix, LLR set, edge 양자화, 채널, seed)을 함께 적어,
> 나중에 "어떤 환경에서 얻은 인사이트인지"를 재현 가능하게 남긴다.

## 2026-10-19 ulpbf_1pass: 저에러 전용 1 pass BF는 에러 16bit 이하에서 유효, CRC 판정이 성공률을 2배 올림

- **실험 폴더**: `003_ulpbf_1pass/` (ieee:11449331, syndrome 갱신 생략 1 pass BF + CRC 판정)
- **환경**: H-matrix `matrix_sel_1.txt` (base 15x145, z=256, N=37120, dv {2:14, 3:69, 4:20, 11:42}),
  LLR set `LLR_MATRIX_HD_matrix_sel_1`, HD 입력, fixed_error t=1-150 격자, seed 0,
  포인트당 1000프레임, 문턱 5종 비교
- **결과**: 1단 단독 성공률(최선 혼합 문턱, CRC 판정) t=8에서 86.2%, t=16에서 46.6%
  (50% 교차 t=15 부근), t>=50은 0%. CRC 거짓 통과 0/55000프레임, 2단 구성 FER = min-sum
  단독 FER (같은 seed, 비열화). 저에러(t<=8)에서 min-sum iteration 잔존비 0.000-0.155
- **인사이트**:
  - ㉮ 논문의 일률 문턱 T=dv-1은 비규칙 H에서 성공률이 1.7%로 떨어진다 (t=8). dv별 혼합 문턱이 필수
  - ㉯ CRC 판정이 syndrome 0 판정보다 성공률을 2배 이상 올린다 (parity 잔여 수용 효과)
  - ㉰ 유효 영역은 좁지만 다단 구조의 맨 앞 단으로는 성립. 이득은 저에러 프레임 비율에 비례
- **판정**: 조건부 유효. 상세: `003_ulpbf_1pass/README.md`

## 2026-10-19 upgdbf: 전역 최대 GDBF는 dv 혼합 H에서 커버가 에러 40bit에 그침

- **실험 폴더**: `004_upgdbf/` (ieee:9902993, penalty 통합 전역 탐색 GDBF)
- **환경**: 위와 같은 H-matrix와 LLR set, HD 입력, EBC 20-150 8포인트 x 300프레임,
  BF 최대 iteration 100, 비교군 7개 (t_active 0/2/4, PGDBF판, penalty 제거판, dv 정규화 진단판, min-sum 기준선)
- **결과**: 복호 가능 상한 EBC 40 (FER 0. 논문 138의 1/3 아래. EBC 60에서 FER 6.3e-2, 120부터 1.0).
  EBC 120 이상에서 dv=2/3 column 플립 0회 (전역 최대 에너지를 dv=11이 독점).
  연산 대리 지표(1bit:3bit=1:3)는 전 포인트에서 min-sum 대비 1.6-14배 손해
- **인사이트**:
  - ㉮ 전역 최대 비교는 dv 균일 부호 전제가 강하다. dv 혼합 구조에서는 저차수 에러 교정 불능
  - ㉯ 논문 내부 주장은 방향 재현: 난수 소프트 제약화로 FER 2.2배 개선, momentum 제거 시 4.8배 악화,
    backtracking 대리 cycle 절감 47% (논문 42% 부합), miscorrection과 floor 징후 0
  - ㉰ dv 균일 부호를 채택하는 경우 재평가 가치가 있다
- **판정**: 실패 (평가 대상 파라미터 기준). 상세: `004_upgdbf/README.md`

## 2026-10-19 atbf_quiescent: 적응 임계와 휴면은 창 8 전제에서 유효, 이득은 1bit 단가 조건부

- **실험 폴더**: `005_atbf_quiescent/` (ieee:5671820, 비트별 적응 임계 BF + 휴면 + 전이 탈출)
- **환경**: 위와 같은 H-matrix와 LLR set, HD 입력, fixed_error 10-150, 포인트당 256프레임,
  창 {4, 8, 16}, λ0 {-4, -8, -16}, θ {2^-1, 2^-2} 격자 후 본 측정
- **결과** (창 8, λ0=-4, θ=2^-1, φ1=-0.25): BF 단계 성공률 E=10에서 95%, E=50에서 45%
  (고정 임계 GDBF는 0%). 합산 FER = min-sum 단독. 휴면으로 활성 비트 5-50% 절감,
  z=256 블록 전부 휴면 비율 94-99% (블록 희석 0.1-17%). ES 탈출로 BF iteration 최대 44% 단축
  (7.12에서 4.00), 오판율 0.4% 이하
- **인사이트**:
  - ㉮ 창 4에서는 휴면이 생산적 반전 구간과 겹쳐 성공률이 95%에서 34%로 떨어진다. 창 8 연장이 전제
  - ㉯ BF+폴백 총 처리 비트는 min-sum 단독의 2.1-3.5배라, 이득은 1bit 비트 단가가 min-sum
    단가의 약 1/4 이하일 때만 성립 (E=10 기준 r<0.26, E=50 기준 r<0.10)
  - ㉰ ES 트리거는 프레임 상태와 무관한 고정 시점에 뜬다 (논문의 13-15회 적응 전이 미재현)
- **판정**: 조건부 유효. 상세: `005_atbf_quiescent/README.md`

## 2026-10-19 bf_stage_switch: 적응 전환은 감지 신호 부재로 무효, 고정 8회 연장이 genie 상한을 달성

- **실험 폴더**: `006_bf_stage_switch/` (ieee:8742682, 다단 BF 적응 전환과 ρ 재튜닝)
- **환경**: 위와 같은 H-matrix와 LLR set, HD 입력, fixed_error 10-150 10포인트 x 320프레임,
  2단 모형 (1bit 포화 min-sum 후 3bit min-sum, C++ HBF 대응. 합성 방식을 고정 4회 실측과 전 프레임 일치로 검증)
- **결과**: genie 상한(전환 시점 0-8 전수 탐색)의 고정 4회 대비 가중 반복(w1:w3=1:3) 절감은
  E<=110에서 0-1.3%, E=120-150에서 4.7-25.7% (풀링 8.3%). genie 선택은 전 프레임이
  "1단계 성공까지 유지"로, 고정 8회 연장과 완전 일치. 감지기 중 주기 2 진동과 플립 0은 발화 0회,
  syndrome weight 정체는 오경보로 고정 4회보다 손해. FER는 전 정책 0
- **인사이트**:
  - ㉮ 4-8회 창의 1단계 실패는 논문이 전제한 루프(진동)가 아니라 느린 수렴이라 감지할 신호가 없다
  - ㉯ 전환 시 CN 상태를 비우고 다시 시작하므로 1단계 잔여 오류 수(ρ)가 2단계 일량에 닿지 않아
    ρ 재튜닝의 인과 경로도 없다
  - ㉰ 파생 발견: `ITER_MAX_HBF` 4에서 8로의 고정 연장이 genie 상한 전부를 달성한다
    (최대 25.7% 절감, 이 측정 범위에서 FER 손실 0. C++ 반영은 결정거리)
- **판정**: 실패 (파생 발견 있음). 상세: `006_bf_stage_switch/README.md`

## 2026-10-19 cbet_column_stop: 열 단위 조기 종료는 기존 PCRC 대비 순증이 음수

- **실험 폴더**: `007_cbet_column_stop/` (ieee:6865738, column 단위 iteration 내부 조기 종료)
- **환경**: 위와 같은 H-matrix와 LLR set, HD 입력, max iteration 120, fixed_error 10-150
  10 간격 x 1000프레임, 기록 전용 측정 (복호 판정은 그대로 두고 정지 조건 성립 자리만 기록, FER 불변. `run.py --verify`로 BaseDecoder와 전 프레임 일치 확인)
- **결과**: CB-ET의 iteration 경계 종료 대비 절감 0.1-5.4%, PCRC 모사(4지점)는 6.8-12.8%.
  PCRC 대비 CB-ET 순증은 전 구간 음수 (-7.2%에서 -14.0%). 거짓 정지 0건, FER 불변.
  genie 수렴 시점까지 CSW가 0에 닿지 않은 프레임 71-96%
- **인사이트**:
  - ㉮ 이 코드베이스의 check sum은 V2C extrinsic 부호 기반이라 전체 패리티 수렴(CSW=0)이
    정보 비트 수렴(PCRC 발화)보다 훨씬 늦다. 확인 주기를 열 단위로 좁혀도 못 뒤집는다
  - ㉯ C++의 BF 1-4회 구간(PCRC 정지 제한 영역)은 py에 BF 엔진이 없어 측정 밖 (후속 과제로 기록)
- **판정**: 실패 (HD min-sum 영역 기준). 상세: `007_cbet_column_stop/README.md`

## 2026-08-17 minsum_dynamic_normalization: 동적 정규화는 격차 임계 T 튜닝이 핵심, 클리핑과 결합 시 최량

- **실험 폴더**: `002_minsum_dynamic_normalization/` (ieee:6865103, min1/min2
  격차 기반 동적 정규화 + 이중 상한)
- **환경**: H-matrix `example_18x147_z256.qc`, seed 0, fixed_error [200, 300],
  frames_per_batch 64, max_iter 20. LLR set과 edge 양자화는 001과 같은 세 조합
  (LLR_MATRIX_HD_1 환경 edge 레벨 {7,5,3,1}, 상한 여유와 비율 복원 환경 {15,11,7,3})
- **결과** (FER, E=200 / E=300):

| 환경 | 무보정 | 고정 0.75 | 동적 (75/100, T=레벨 간격) | 클리핑(4,8)+동적 |
|------|--------|-----------|---------------------------|------------------|
| LLR_MATRIX_HD_1 환경 | 4.84e-01 / 9.84e-01 | 1.00 / 1.00 | 7.97e-01 / 1.00 (악화) | 미실행 (클리핑 반전 불능 기지) |
| 상한 여유 환경 | 1.00 / 1.00 (전 프레임 실패) | 0.00 / 1.00 | 0.00 / 4.53e-01 | **0.00 / 5.21e-02 (전 조합 최량)** |
| 비율 복원 환경 | 0.00 / 1.17e-02 (정상) | 1.56e-02 / 8.59e-02 | 3.91e-03 / 5.73e-02 (악화) | 1.00 / 1.00 (전 프레임 실패) |

- **인사이트**:
  - ㉮ 격차 임계 T는 본체의 min2=RESET 승격 근사 때문에 튜닝이 핵심다: min1
    교체 시 min2가 실제 둘째 최솟값이 아니라 RESET으로 올라가 격차가
    과대평가되므로, T가 인접 레벨 격차 이하이면 알파 high 선택율이 0.99로
    쏠려 무보정으로 퇴화한다. T = edge 레벨 간격(두 레벨 이상 차이)이 가이드
  - ㉯ 이득 조건에서 동적 선택은 고정 정규화를 명확히 이긴다 (상한 여유 환경
    E=300: 고정 1.00, 동적 4.53e-01). 이득의 원천이 정규화 자체가 아니라
    격차 기반 선택임이 분리 확인됨
  - ㉰ 클리핑(001)과 결합하면 각자 단독보다 크게 낫다 (E=300 5.21e-02):
    클리핑이 E=200 수렴을 주도(avg_iter 3.8)하고 동적 정규화가 E=300 실패
    프레임을 추가로 살린다. 기본형은 결합형
  - ㉱ 알파 low에 문턱 거동이 있다: 0.75는 포화 실패 루프를 끊지만 0.85는 못
    끊어 무보정과 같아진다 (감쇠가 포화 분포를 바꿔 선택율 자체가 함께 움직임:
    같은 T=4에서 0.75면 선택율 0.321, 0.85면 0.983). 0.5는 과감쇠로 손해
  - ㉲ 조건 구조는 001과 동일: ch 대비 edge 상한 여유가 없으면(LLR_MATRIX_HD_1,
    비율 복원 환경) 어떤 정규화도 손해. 사전 지표 `ch / (edge상한 × dv)`
    공유
- **상세**: `002_minsum_dynamic_normalization/README.md`, 재현은 scan.py +
  config_headroom.json (조합 표기 P,Q,알파low%,알파high%,격차T)

## 2026-08-14 minsum_dual_clip: 클리핑 효과는 ch 대비 edge 상한 여유가 결정

- **실험 폴더**: `001_minsum_dual_clip/` (ieee:9496601, CNU min1/min2 이중 상한 클리핑)
- **환경**: H-matrix `example_18x147_z256.qc` (base 18x147, z=256, col degree
  {2:17, 3:1, 4:129}), seed 0, fixed_error [200, 300], frames_per_batch 64,
  max_iter 20. LLR set과 edge 양자화는 아래 세 조합
- **결과** (E=200 FER):

| 환경 | LLR set | edge 상한 | 무클립 기준선 | 논문 가이드 클립 (P=상한/4, Q=상한/2) |
|------|---------|-----------|--------------|--------------------------------------|
| LLR_MATRIX_HD_1 환경 | 파일 (dv별 ch 5/10/13/28) | 7 | 4.84e-01 | 1.00e+00 (전 클립 악화) |
| 상한 여유 환경 (config_headroom.json) | 균일 ch=8 | 15 | 1.00e+00 (전 프레임 실패) | **0.00e+00 (0/256 완전 복구)** |
| 비율 복원 환경 (config_balanced.json) | 균일 ch=16 | 15 | 0.00e+00 (정상) | 1.00e+00 (전 프레임 실패) |

- **인사이트**:
  - ㉮ 클리핑의 득실은 H-matrix 품질이 아니라 **채널 LLR 스케일 대비 edge magnitude
    상한의 여유(성장 여지)**가 결정한다. 여유가 없으면(LLR_MATRIX_HD_1 환경, 비율 복원
    환경) 클리핑은 반전 가능성만 깎아 악화시키고, 여유가 커서 무클립이 과확신으로
    전 프레임 실패하는 상한 여유 환경에서는 논문 가이드값이 FER 1.0을 0으로 되돌린다
  - ㉯ 반전 불능 경계는 반전 가능 조건으로 정확히 예측된다: dv 열의 최대 extrinsic
    `Q + (dv-1)×P`가 그 dv의 ch보다 작으면 해당 열은 채널 결정을 영원히 반전
    불능. 관측 전례와 일치 (LLR_MATRIX_HD_1 환경 dv=4 ch=10: (2,3)은 9로 반전 불능, (2,5)는
    11로 반전 가능. 비율 복원 환경 dv=4 ch=16: (4,8)은 16 동률로 사실상 반전 불능)
  - ㉰ 같은 P에서 Q를 키우면 일관 개선: 이중 상한(P<Q)이 단일 상한(P=Q)보다
    낫다는 논문 구조 주장은 세 환경 모두에서 방향 재현
  - ㉱ dv=2 열(ch=28, 상한 7×2=14)은 LLR_MATRIX_HD_1 환경에서 클리핑과 무관하게 처음부터 반전
    불능 (전 실행에서 에러 22.7개 동결, TODO의 기지 위반). 성공 판정이
    information 구간만 검사하므로 FER에는 직접 안 걸림
  - ㉲ 적용 판단 기준 도출: 평가할 LLR set에서 dv별 `ch / (7×dv)` 비율을 먼저
    보면 클리핑 여지가 있는지 사전 판정 가능. 비율이 1에 가까우면 여지 없음
- **상세**: `001_minsum_dual_clip/README.md`, 재현은 scan.py + config_headroom.json,
  config_balanced.json

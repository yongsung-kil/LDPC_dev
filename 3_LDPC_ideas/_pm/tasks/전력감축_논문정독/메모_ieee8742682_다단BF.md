## 1. 논문이 푸는 문제

- ㉮ SD BF 디코더(GDBF, WBF 계열)는 저복잡도이지만 BP 대비 성능 격차가 크다. 이 격차를 추가 복잡도 거의 없이 줄이는 것이 목표다
- ㉯ 기존 다단 디코더(BP 뒤 OSD, 빠른 WBF 뒤 BP 등)는 두 가지 문제가 있다
  - ㉠ 단계 간 구조가 달라 구현 복잡도와 저장량이 크게 늘어난다
  - ㉡ 단계 전환 시점을 고정 반복 횟수로 정하는데, 그 임계값은 시뮬레이션으로만 찾을 수 있고 SNR, 부호, 알고리즘에 따라 달라진다
- ㉰ 이 논문은 두 문제를 함께 푼다. 모든 단계가 같은 BF 구조를 공유해 복잡도 증가를 루프 감지기 하나로 한정하고, 전환 시점은 고정 횟수 대신 디코딩 루프(진동) 감지로 적응적으로 정한다

## 2. 기법 상세

### 2.1 바탕 관측

- ㉮ SD BF 디코더는 일정 반복 후 진동하는 비트 결정 패턴에 빠지기 쉽다. 같은 미완성 복호 벡터가 주기적으로 재등장하는 무한 루프이고, 이것이 복호 실패로 이어진다. 따라서 루프가 감지된 때가 합리적인 SS 시점이다
- ㉯ 복호 실패(루프) 시점의 잔여 오류 수는 작다. (1008, 504) 정규 PEG 부호에서 실패 프레임의 잔여 오류 CDF를 재면 특히 높은 SNR에서 몇 비트만 남는다 (Fig. 1)
- ㉰ 루프의 주원인은 극단적 채널 값이다. 아주 큰 수신값은 FF를 지배하고, 아주 작은 수신값은 해당 가중치와 검사식을 무력화한다. 그래서 2단계 디코더는 채널 값과 무관해야 하고, 이 조건이 대부분의 SD BF를 배제하여 Gallager HD BF가 선택된다
- ㉱ Gallager HD BF는 girth 6에서 무게 (dv+1)/2 미만, girth 8에서 dv-1 이하의 오류 패턴 정정을 보장하고, 실험적으로는 훨씬 큰 무게(위 부호에서 30 미만)까지 높은 확률로 정정한다 (Fig. 2). 즉 "1단계가 남긴 소수의 오류를 높은 확률로 치우는" 2단계 역할에 맞는다
- ㉲ Gallager FF는 IMWBF, RRWBF, GDBF FF의 특수형(파라미터를 0 또는 1로 둔 꼴)이므로 같은 디코더 하드웨어에 추가 복잡도 없이 들어간다

### 2.2 FF 정리 (추출 텍스트에서 재구성, 합은 m이 M(n)을 도는 합)

- ㉮ Gallager HD BF: En = -Σ (1 - 2 sm)
- ㉯ IMWBF: En = -α|yn| - Σ wmn (1 - 2 sm), wmn은 검사식 m에 연결된 다른 변수 노드 수신값 크기의 최소, α > 0
- ㉰ RRWBF: En = -Σ wmn^(R) (1 - 2 sm) (신뢰도 비 가중)
- ㉱ GDBF: En = -xn yn - Σ (1 - 2 sm), xn = 1 - 2 un
- 매 반복 FF 최대인 비트(들)를 플립하고 syndrome을 갱신한다. syndrome이 0이거나 반복 한도 lmax에 닿으면 종료한다

### 2.3 루프 감지기 (SS 시점 결정)

- ㉮ 현재 반복 i의 복호 벡터 u(i)가 과거 반복 j의 u(j)와 같으면 길이 i-j의 루프로 판정한다
- ㉯ 저장량 절감 장치 두 개를 둔다
  - ㉠ L1: 루프 감지를 L1회 반복이 지난 뒤부터 활성화한다 (루프는 보통 일정 반복 후에 생기므로)
  - ㉡ L2: 직전 L2회 반복의 벡터와만 비교한다 (루프 길이는 보통 짧으므로)
- ㉰ L1, L2는 경험적으로 쉽게 정해지고, SNR에 의존하는 감지기 파라미터는 없다. 루프 발생 시점은 1단계 알고리즘과 동작 SNR이 자동으로 정한다 (이 점이 고정 횟수 전환과의 핵심 차이)
- ㉱ 2단계에서 3단계로 넘어갈 때도 같은 감지기를 쓰되, 2단계 반복 수가 작으므로 L1 = 0으로 둔다. 감지기는 같은 단계 안의 벡터만 비교한다

### 2.4 알고리즘 구성

- ㉮ 2SBF (Algorithm 1 요지)
  - ㉠ 1단계: 임의의 SD BF로 복호. syndrome 0 또는 lmax면 종료
  - ㉡ 루프가 감지되면 2단계로 전환
  - ㉢ 2단계: Gallager HD BF로 이어서 복호. syndrome 0 또는 lmax까지 반복
  - 반복 카운터 l은 단계를 넘어 하나로 이어 쓴다 (총 반복 예산 공유)
- ㉯ 3SBF: 2단계(Gallager BF)에서 또 루프가 감지되면 3단계 RBF로 전환한다. RBF는 Gallager FF를 그대로 쓰되, FF 최대값 비트 집합 F(크기 p)에서 q개(0 < q <= p)를 무작위로 골라 플립한다. 무작위 이동으로 국소 평탄면을 탈출하는 장치다
- ㉰ 같은 SD BF 알고리즘으로 되돌아가는 선택지는 배제한다. FF가 채널 값의 함수라서 같은 극단 값이 같은 오류 패턴을 다시 만들고 또 루프에 빠지기 때문이다

### 2.5 1단계 파라미터 재튜닝 (설계 지침 ㉯의 구체 내용)

- ㉮ 단독 SD BF에서는 FF의 스케일 인자 α를 수렴 오류율(FER, BER) 최소 기준으로 고른다 (IMWBF에서 α 약 0.2)
- ㉯ 다단에서는 기준이 바뀐다. 2단계 성공 확률이 1단계가 남긴 잔여 오류 수에 달려 있으므로, 1단계는 "실패가 일어났다는 조건 아래 프레임당 평균 잔여 오류 수"를 최소화해야 한다
- ㉰ 이를 위한 새 지표: ρ(α) = PB(α) × N / PF(α). PB는 BER, PF는 FER, N은 부호 길이. 실패 프레임당 평균 잔여 오류 비트 수를 뜻한다
- ㉱ 위 부호에서 ρ(α) 최소는 α 0.5-1 구간(SNR 의존)에 있고, 단독 최적 α 0.2와 다르다. IMWBF-2SBF는 α = 0.5 또는 1에서 α = 0.2보다 수렴 FER이 좋다 (Fig. 6, 7)
- ㉲ 최적 α는 SNR의 함수지만 SNR에 둔감한 준최적 α를 하나 고를 수 있다

## 3. 보고된 이득

측정 조건: (1008, 504) 정규 PEG 부호(PEGReg 504 × 1008, dv = 3, girth 8), BPSK, AWGN, L2 = 20, lmax 50 또는 200. IMWBF와 MMWBF 계열은 α = 0.2.

- ㉮ GDBF-2SBF와 다중 비트 플립판 m-GDBF-2SBF: FER 약 10^-5에서 GDBF 대비 약 1dB 이득
- ㉯ WBF 계열 2SBF: 같은 FER에서 원 SD BF 대비 최소 1.5dB 이득
- ㉰ 3SBF 대 2SBF: 낮은, 중간 SNR에서 수렴 FER 개선, FER 약 10^-5에서 약 0.25dB 추가 이득
- ㉱ 전환 시점 비교 (SNR 5.5dB, Fig. 5)
  - ㉠ 이른 고정 전환(20회/40회): 뚜렷한 FER 손실
  - ㉡ 늦은 고정 전환(100회/200회): 수렴 FER은 비슷하나 1, 2단계에서 불필요한 연산을 쓰고 수렴이 크게 느려짐
  - ㉢ 루프 감지 전환: 준최적 전환 시점으로 FER과 수렴 속도 모두 우위
- ㉲ α 재튜닝: IMWBF-2SBF에서 α = 0.5 또는 1이 α = 0.2보다 수렴 FER 우수 (Fig. 7)
- 유의: 전력이나 에너지 수치는 보고하지 않는다. 평균 반복 수 감소는 Fig. 5의 수렴 곡선으로만 제시되어 정확한 수치는 원문 확인 필요

## 4. HBF/HD 적용 방법

우리 구조는 논문과 단계 순서가 반대다. 논문은 SD BF를 먼저 돌리고 HD BF로 마무리하지만, `0_LDPC_original/src/decoder.cpp`는 HD 입력에서 1bit 정밀도 HBF 단계를 먼저 돌리고(에너지 절약 목적) 실패하면 3bit min-sum으로 올라간다. 그래도 전환 시점 결정과 파라미터 재튜닝 기준은 그대로 옮겨진다.

### 4.1 대응 관계

- ㉮ 논문의 1단계(SD BF) = 우리의 1bit HBF 단계 (`flag_BF_on`이 켜진 처음 `ITER_MAX_HBF`(4)회, 1bit 포화 메시지 min-sum)
- ㉯ 논문의 2단계(Gallager HD BF) = 우리의 3bit min-sum 단계 (잔여 오류 청소 담당)
- ㉰ 논문의 SS(루프 감지) = 우리의 고정 4회 전환을 대체할 후보
- ㉱ 논문의 α 재튜닝 = 우리의 `syn_th_BF0`(HBF 진입 임계)와 1bit 단계 포화 크기(`EDGE_MAG_7`/`EDGE_MAG_8`) 튜닝 기준의 교체

### 4.2 코드 상 삽입 지점

- ㉮ 진입 판정: `Select_BF()`(decoder.cpp 2082행 부근)가 iteration 0의 syndrome weight < `syn_th_BF0`로 `flag_BF_on`을 켠다. 이 부분은 유지한다
- ㉯ 전환 시점: 단계 경계가 `iter <= ITER_MAX_HBF` 상수 비교로 코드 전반에 박혀 있다 (1bit 정밀도 분기 4056-4058행, 전처리 스케줄 1148-1149행, 1816-1828행, 2304-2312행 등). 적응 전환은 이 상수를 프레임마다 정해지는 변수(예: `iter_switch_HBF`)로 바꾸는 작업이다
- ㉰ 관측량: 37000bit급 복호 벡터를 반복마다 저장해 비교하는 것은 비현실적이므로 대리 관측을 쓴다
  - ㉠ syndrome weight 추이: 정체 또는 재상승(sw[i] >= sw[i-1], 또는 주기 2 진동 sw[i] == sw[i-2])을 루프 신호로 본다. syndrome weight는 이미 계산되고 있어 추가 비용이 가장 작다
  - ㉡ 반복당 플립 수(또는 부호 바뀐 변수 노드 수)가 0이거나 두 반복 주기로 같은 값 반복
  - ㉢ 복호 벡터의 체크섬(해시) 레지스터를 두고 직전 2-4개와 비교 (논문의 벡터 비교를 L2 = 2-4로 축소한 꼴)
- ㉱ 전환 방향 두 가지를 구분한다
  - ㉠ 조기 전환: 1bit 단계가 반복 1-2회에서 이미 정체면 4회를 채우지 않고 3bit로 넘어간다. 하드웨어 변경이 작고(전환 시점이 당겨질 뿐), 낭비 반복을 줄인다
  - ㉡ 연장: syndrome weight가 계속 줄고 있으면 4회를 넘겨 1bit 모드를 유지해 3bit 단계 자체를 회피한다. 에너지 이득은 이쪽이 크지만, 전처리가 `ITER_MAX_HBF + 1` 직전에 고정 스케줄되어 있어 파이프라인 변경 폭이 크다 (변경 등급 Decision)
- ㉲ 파라미터 재튜닝: `syn_th_BF0`와 1bit 단계 포화 크기를 "1bit 단계 단독 성공률 최대" 기준이 아니라 "전환 시점 잔여 오류 수 ρ 최소" 기준으로 다시 고른다. ρ가 작을수록 3bit 단계가 적은 반복으로 끝나므로 전체 에너지와 FER에 함께 이롭다는 것이 논문의 지침이다
- ㉳ PCRC와의 관계: PCRC 조기 종료는 성공을 빨리 알아채는 장치이고, 루프 감지는 실패를 빨리 알아채는 장치라서 상보적이다. 서로 간섭 없이 공존한다

## 5. 예상 이득과 위험

- ㉮ 예상 이득
  - ㉠ 조기 전환: 1bit 단계에서 희망 없는 프레임이 반복 1-2회 만에 3bit로 넘어가면 프레임당 1-3회의 1bit 반복과 그만큼의 지연이 준다. 3bit가 더 강력하므로 FER은 유지되거나 좋아진다
  - ㉡ 연장: 1bit 반복 몇 회 추가로 3bit 단계 진입 자체를 피하는 프레임이 생기면 에너지 이득이 가장 크다 (3bit 반복은 1bit 반복보다 메시지 폭과 메모리 접근이 크다)
  - ㉢ ρ 기준 재튜닝은 하드웨어 변경 없이 파라미터 값만 바꾸므로 비용 대비 효과가 좋다
- ㉯ 위험과 간극
  - ㉠ 관측 창이 좁다. 논문은 lmax 50-200에서 수십 회 반복 후의 루프를 감지하지만, 우리 1bit 단계는 4회뿐이라 루프가 자리 잡기 전이다. 주기 2 진동 정도만 잡을 수 있고, 이득 상한이 논문보다 훨씬 작을 수 있다
  - ㉡ 부호 규모 간극: 논문은 N = 1008, dv = 3, 정규 부호이고 우리는 약 37000bit QC(z = 256급) 비정규 부호다. 진동 통계와 잔여 오류 분포가 다를 수 있다
  - ㉢ 알고리즘 간극: 우리 1bit 단계는 순수 Gallager BF가 아니라 1bit 포화 메시지 min-sum이다. 플립 대상 선정 방식이 달라 루프 패턴 통계가 논문과 다르다
  - ㉣ 연장 방향의 FER 위험: 1bit 단계를 늘렸는데 오류가 늘어난 채 전환되면 3bit 단계 시작 상태가 나빠진다. 총 반복 예산이 짧은 우리 환경에서는 수렴 지연이 곧 FER 손실이다 (논문 Fig. 5의 늦은 전환 손실이 같은 현상)
  - ㉤ 150bit 영역과의 간극: 프레임당 오류 150bit급은 `syn_th_BF0`에 걸려 HBF에 진입하지 않으므로 이 기법의 영향권 밖이다. 이득은 HBF 진입 프레임(저오류 구간)에 한정된다
- ㉰ 검증 포인트
  - ㉠ 1bit 단계 4회 안에서 루프(진동)가 실제로 얼마나 발생하는지, 발생 시점 분포
  - ㉡ syndrome weight 정체가 1bit 단계 최종 실패를 반복 1-2회에서 얼마나 정확히 예측하는지 (오경보율과 미검출률)
  - ㉢ ρ 기준으로 `syn_th_BF0`와 포화 크기를 다시 골랐을 때 FER과 평균 반복의 변화

## 6. 실험 설계 초안

환경: `2_LDPC_base/src/decoder.py`의 BaseDecoder를 상속하되, BF 계열이므로 교체 함수가 아니라 `decoder_main` 전체를 재정의한 2단 모형을 만든다. 1단계는 메시지를 1bit로 포화시킨 min-sum(실제 C++ HBF와 같은 구조), 2단계는 3bit min-sum. HD 입력.

- ㉮ 기준선: 고정 4회 전환 모형으로 FER, 평균 총 반복, 에너지 대리 지표를 잰다
  - ㉠ 에너지 대리 지표: 가중 반복 수 = (1bit 반복 수 × w1) + (3bit 반복 수 × w3). 가중치는 메시지 비트 폭 비(예: w1 = 1, w3 = 3)로 두고 민감도도 본다
  - ㉡ 프레임당 주입 오류 수를 0-150bit 구간에서 구간별(예: 10bit 단위)로 돌린다
- ㉯ genie 상한 실험: 프레임마다 전환 시점을 0-8회로 전수 탐색해 사후 최적 전환이 주는 FER과 가중 반복의 상한을 잰다. 이 상한이 작으면 적응 전환 자체를 접는다 (등록 판정의 1차 관문)
- ㉰ 감지기 후보 비교: 아래 각각을 genie 상한과 기준선 사이에서 평가한다
  - ㉠ syndrome weight 정체 (sw[i] >= sw[i-1])
  - ㉡ syndrome weight 주기 2 진동 (sw[i] == sw[i-2])
  - ㉢ 플립 수 0 또는 플립 집합 반복
  - ㉣ 복호 벡터 해시 반복 (논문 원형, L2 = 2-4)
  - 측정 항목: FER 유지 여부, 평균 가중 반복, 조기 전환률과 오경보율
- ㉱ ρ 재튜닝 실험: 1bit 단계 포화 크기와 진입 임계를 바꿔 가며 전환 시점 잔여 오류 수 ρ와 최종 FER, 가중 반복을 함께 잰다. "ρ 최소 파라미터가 1단계 단독 성공률 최대 파라미터보다 전체 성능이 좋다"는 논문 주장을 우리 구조에서 확인한다
- ㉲ 연장 방향 별도 실험: 전환 상한을 4회에서 6-8회로 늘린 변형으로, 3bit 진입 회피 프레임 비율과 FER 열화 여부를 잰다 (하드웨어 반영은 Decision이므로 수치만 확보)

## 8. 등록 권고

**중**. 적응형 전환과 ρ 기준 파라미터 재튜닝은 현 고정 4회 HBF 구조에 대응 지점이 분명하고, 특히 ρ 재튜닝은 하드웨어 변경 없이 쓸 수 있어 에너지 목표와 잘 맞는다. 다만 1bit 단계가 4회뿐이라 루프 감지의 관측 창이 좁고 부호 규모와 알고리즘 간극도 커서, genie 상한 실험으로 이득 상한을 먼저 확인한 뒤에 투자 여부를 정하는 것이 안전하다.

# 태스크: low error 영역 전력 감축 논문 정독

## 목적

low error 영역(4KB급 codeword, 프레임당 에러 0-150bit)에서 디코딩 전력을 줄이는
논문 아이디어를 정독하고, 아이디어 현황표에 등록할 후보를 추린다.

## 배경

- ㉮ 적용처는 `0_LDPC_original`의 HBF(1bit 정밀도 bit flipping 단계)와 HD(hard decision, 경판정) 디코딩이다
- ㉯ 현 구조: iteration 0에서 `Select_BF()`가 syndrome weight로 HBF 진입을 정하고,
  `ITER_MAX_HBF`(4)회 1bit 모드 후 3bit min-sum 모드로 전환한다. Partial CRC(4개
  termination point) 조기 종료가 이미 있다
- ㉰ 논문 아카이브(형제 저장소 LDPC_Paper_Analysis, 22221편) 조사 경과:
  - 1차 조사(키워드 검색과 abstract 검토)로 후보 약 60편 선별: [1차조사_후보60편.md](1차조사_후보60편.md)
  - 2차 검증(abstract 30편 대조, 상위 3편 전문 확인)으로 정독 대상 5편 확정

## 산출물

- ㉮ 논문별 적용 메모 5편 (쉬운 설명, 기법, 보고된 이득, HBF/HD 적용 방법, 실험 설계 초안, 등록 권고)
- ㉯ 아이디어 현황표 등록 5건 (003-007)과 py 스크리닝 결과 (실험로그.md에 5건 기록)

## 스크리닝 결과 요약

| 폴더 | 판정 | 한 줄 결과 |
|------|------|-----------|
| `003_ulpbf_1pass/` | 조건부 유의미 | 에러 16bit 이하 1단 전용, CRC 판정 비열화와 미검출 0 |
| `004_upgdbf/` | 무의미 | dv 혼합 H에서 전역 최대 비교 비호환, 커버 에러 40bit |
| `005_atbf_quiescent/` | 조건부 유의미 | 휴면 절감 5-50%, ES 단축 44%. 창 8 연장과 1bit 단가 조건 |
| `006_bf_stage_switch/` | 무의미 | 감지 신호 부재. 파생: 1bit 창 8회 고정 연장이 genie 상한 달성 |
| `007_cbet_column_stop/` | 무의미 | 기존 PCRC 대비 순증 음수 |

## 안전성

- 문서와 py 실험 폴더 작업만 있다 (C++ 코드 변경 없음). 변경 등급 Safe

## 미결정 사항

- ㉮ C++ 반영 범위 (ITER_MAX_HBF 4에서 8로 연장, 003 ULPBF 1 pass 단 추가,
  005 휴면과 조기 탈출. 판정요청으로 묻는다)
- ㉯ BF 계열 py 공용 엔진은 만들지 않고 아이디어 폴더마다 자체 구현으로 확정
  (병렬 실험의 독립성 우선)

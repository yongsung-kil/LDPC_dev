# 001 이중 상한 클리핑: th의 클리핑 역할과 기여 가능성 분석

## 질문

- ㉮ `LLR_MATRIX_HD_matrix_sel_1.txt`의 th가 이미 클리핑 역할을 하고 있는가
- ㉯ 이 파일 형식(dv별, iteration 그룹별, CSW별로 ch와 th를 주는 테이블)을 쓰는 시스템에 논문 ieee:9496601의 CNU min1/min2 이중 상한 클리핑이 기여할 수 있는가

## 용어

- ㉮ dv: 변수 노드 차수. 한 비트가 연결된 검사식 수
- ㉯ ch: 테이블이 dv별로 주는 채널 LLR 크기. flip 도메인에서 항상 양수로 더해진다
- ㉰ th (th1, th2, th3): 변수 노드가 내보내는 V2C 메시지 크기를 레벨 {7,5,3,1}로 양자화하는 임계값. |raw| ≥ th1이면 7, ≥ th2이면 5, ≥ th3이면 3, 아니면 1
- ㉱ raw: V2C 양자화 전 값. ch + (다른 dv-1개 edge에서 들어온 C2V 합)
- ㉲ extrinsic: 채널 외에 다른 검사식이 보태는 지지. 한 변수 노드의 extrinsic 합은 dv개 C2V의 합
- ㉳ min1, min2: 검사 노드에 들어온 V2C 크기의 최솟값과 둘째 최솟값. C2V 크기는 자기 edge가 min1 위치면 min2, 아니면 min1
- ㉴ RESET 승격: 본체 CNU가 min1을 새 값으로 교체할 때 min2를 실제 둘째 최솟값이 아니라 최대 레벨 7로 올리는 규칙 (`2_LDPC_base/src/decoder.py` 213~217행, 하드웨어 특성)
- ㉵ P, Q: 논문의 두 상한. min1은 P로, min2는 Q로 자른다 (P ≤ Q). (7,7)은 자르지 않는 조건이다
- ㉶ CSW: 직전 iteration의 신드롬 무게. 테이블 row 선택에 쓴다
- ㉷ 사전 지표: 클리핑 여지를 미리 재는 비율 ch / (edge 상한 7 × dv). 채널 LLR 대 extrinsic 합 최댓값의 비
- ㉸ 001의 세 환경: 상한 여유 환경(전 dv 균일 ch 8, edge 레벨 {15,11,7,3}), 비율 복원 환경(균일 ch 16, 같은 레벨), LLR_MATRIX_HD_1 환경(파일, 레벨 {7,5,3,1}). 001에서 클리핑은 상한 여유 환경에서만 이득이었다

## 답

### 질문 ㉮: th는 클리핑을 대신하지 못한다

- ㉮ min1 쪽: th가 어떤 레벨을 도달 불가로 만들면 그 dv의 V2C 상한이 내려가고, 그것이 연결된 검사 노드의 min1 상한이 된다. 이 파일에서 레벨 7 도달 불가 칸은 228칸(57 row × 4 dv) 중 2개뿐이다 (C2). 검사 노드 출력의 min1 상한이 7 아래로 내려가는 row는 57개 중 2개다 (C3)
- ㉯ min2 쪽: RESET 승격 때문에 th로는 min2 상한을 낮출 수 없다. 두 row의 실효 쌍은 (5,7)이다 (C3)
- ㉰ 압축 정도: 레벨 7을 내는 데 채널 외에 필요한 extrinsic 지지(th1 - ch)는 중앙값 +1~+3으로 균일 임계값 [7,5,3]과 큰 차이가 없다 (C4). 오히려 하위 임계값이 레벨 5, 3, 1을 비워 분포를 7 쪽으로 미는 칸이 50개라 (C2), th는 클리핑과 반대 방향으로 작용하는 자리가 더 많다
- ㉱ 결론: 이 파일의 th는 클리핑이 아니라 dv별 양자화 지도이며, 채널 대 extrinsic 균형은 ch가 쥔다 (C5)

### 질문 ㉯: 기여할 수 있다. 다만 사전 지표로는 판정이 서지 않으므로 아래 절차로 실험해 정한다

- ㉮ 논문이 이 시스템에 새로 주는 것은 min1 상한 P와 min2 상한 Q < 7 두 가지다. P는 특정 row에서 th가 근사할 수 있지만 Q < 7은 RESET 승격 때문에 th와 ch 어느 조합으로도 만들 수 없다 (C6)
- ㉯ 사전 지표는 dv에 따라 반대 답을 준다. 정보 구간 column block 수 기준 지배 열 dv3은 0.29로 001의 손해 환경(0.27, 0.36) 옆이고, edge 수 기준 지배 열 dv11은 0.13으로 이득 환경 옆이다 (C5). 지표만으로는 판정이 서지 않는다
- ㉰ 반복 120에 restart가 없어 검사 노드 상태가 한 번도 클리어되지 않으므로, 논문이 든 이득 근거(반복 후반의 포화)는 001의 20 iteration보다 이 파일에서 더 크게 작동할 수 있다. 반대로 테이블의 후반 저 CSW row는 ch를 0~5로 내려 extrinsic 우위를 의도하므로, 전역 한 쌍의 (P,Q)는 그 구간과 방향이 어긋난다 (C7)
- ㉱ 논문의 비트폭 절감 이득은 이 시스템에 없다. 가능한 이득은 FER뿐이다 (C9)
- ㉲ 사후 스캔의 양성은 강한 증거, 음성은 약한 증거다. 음성이면 py 안에서 클리핑을 켠 채 ch를 국소 재탐색하는 중간 경로로 넘어가고, 외부 재최적화는 그 뒤에 판단한다 (C8, C10)

## 주장

- **C1. th의 동작 모델**: raw = ch + (다른 dv-1개 edge의 C2V 합). ch ≥ 0일 때 |raw| 최댓값 = ch + (dv-1)×7 (일반형은 |ch| + (dv-1)×7. 이 파일은 ch, th가 모두 0 이상). 캐스케이드는 |raw| ≥ th1이면 7, ≥ th2이면 5, ≥ th3이면 3, 아니면 1이다. th_k > |raw| 최댓값이면 그 레벨은 도달 불가다. 어느 dv의 상한이 내려가도 다른 dv의 (dv-1)×7 항은 min1, min2가 7 이하라는 사실에서 오므로 내려가지 않아, 1회 계산이 곧 고정점이다
- **C2. 도달 불가 칸**: 228칸 중 레벨 7 도달 불가는 2개다 (row 2 dv3: ch 13, th1 31, 최댓값 27. row 57 dv2: ch 0, th1 9, 최댓값 7). 레벨 5 도달 불가 26칸, 레벨 3 17칸, 레벨 1 7칸이며 도달 불가 레벨이 있는 row는 57개 중 33개다. 하위 레벨이 비면 메시지가 건너뛰어 분포가 7 쪽으로 밀린다. row 57 dv2 칸은 패리티 구간이라 성공 판정에 직접 들어가지 않는다 (다만 dv2 column이 모든 검사 노드의 마지막 처리 edge라 RESET 승격 여부를 결정한다)
- **C3. 검사 노드 실효 상한**: th가 정하는 것은 min1 상한뿐이다. 검사 노드 row block마다 연결 column block 수는 dv11 30~32개, dv4 4~6개, dv3 13~15개, dv2 1~2개이고, min1 상한은 연결 dv 실효 상한의 최솟값이다. min2 상한은 RESET 승격 때문에 항상 7이다. row 2(iteration 2~4, CSW 984 초과)와 row 57(iteration 101~120, CSW 16 이하)에서 실효 (P,Q) = (5,7), 나머지 55 row는 (7,7). 제한 dv가 column 61(dv3)과 131(dv2)부터라 같은 row가 이어지는 다음 iteration부터 반영된다. 이 통계는 57 row를 균등 취급한 것이며 실제 선택 빈도 가중은 측정하지 않았다 (기존 실행 로그에 CSW 자료 없음)
- **C4. 압축 정도**: need7 = th1 - ch의 중앙값은 dv별 +1~+3이고 균일 기준선 th1 = 7의 -3~+1과 큰 차이가 없다. dv11만 th1 중앙값 13으로 기준선보다 6 높다. need5 = th2 - ch 중앙값은 -1~-3이나 th2 > ch인 row가 dv별 6~19개다
- **C5. 채널 대 extrinsic 균형을 쥐는 값은 ch다** (0~31, CSW와 iteration별 변동). 사전 지표 중앙값은 dv11 0.13, dv4 0.25, dv3 0.29, dv2 0.50이다. 001의 세 관측점(이득 0.13, 손해 0.27과 0.36)에 대면 지배 열을 무엇으로 잡느냐에 따라 반대 답이 나온다. 지표의 이득과 손해 경계는 레벨 {15,11,7,3}에서만 교정됐고 이 파일은 {7,5,3,1}이라 방향 참고에 그친다
- **C6. 논문이 새로 주는 자유도**: ㉮ min1 상한 P. ㉯ min2 상한 Q < 7. 갱신 불변식상 min1 = min2는 둘 다 7(포화)일 때뿐이므로 논문의 전제(저비트폭에서 min1 = min2가 잦다)는 포화 상태에서만 성립한다. 역할별 비대칭(min1 위치 edge는 7을 받음)은 RESET 승격이 이미 만들고, 논문이 더하는 것은 두 상한이다. 001 결론 ㉰("같은 P에서 Q를 키우면 개선")은 LLR_MATRIX_HD_1 환경에서만 비교가 있었고 단일 상한 대비 상대 개선이다. 이 시스템에서 Q < 7은 과확신 억제보다 RESET 승격이 만든 과대 추정의 교정으로 작동할 수 있어 논문 제약 밖의 (7,5) 변형도 후보다. 논문 원형은 (P, Q, 정규화 계수 알파) 삼중 튜닝이고 이 시스템에는 알파가 없다. 002는 이득 조건에서 클리핑 단독 FER 1.00 대 클리핑과 동적 정규화 결합 5.21e-02를 보였다
- **C7. 사후 적용의 해석**: 001에서 클리핑의 득실을 가른 것은 ch 대비 edge 상한의 여유였다. 이 파일은 사전 지표가 dv별로 갈리고, max_iter 120에 restart 0이라 반복 후반 포화 조건은 001보다 강하며, 후반 저 CSW row(ch 0~5)는 extrinsic 우위를 의도하므로 전역 (P,Q)와 방향이 어긋난다. 따라서 사후 스캔의 양성은 강한 증거이고 음성은 약한 증거다. 실패 원인이 과확신이 아니라 특정 dv 열의 반전 불능이면 (P,Q) 스캔은 답을 주지 못한다
- **C8. 재최적화 경로 셋**: ㉮ 사후 스캔 (채널 2개, 다섯 쌍, 256프레임이면 약 25분). ㉯ py 국소 재탐색: 클리핑을 켠 디코더로 dv별 ch 배율 4개를 좌표 하강(수준 5개)하면 (P,Q)당 약 50분, 전역 배율 하나면 약 12분. 난수가 디코더와 독립이라(`run.py` 586행) 프레임이 쌍 사이에 짝지어진다. ㉰ 외부 완전 재최적화: 5_DAO는 Ref-C 실행 파일을 배치로 실행해 FER 파일을 읽는다 (`5_DAO/SRC/DAO_Main.py` 6540, 7910~7969행). 저장소의 `5_DAO/Input/Ref_C/` 아래 EXE와 SRC 폴더가 비어 있어 이 환경에서는 실행할 수 없고, C++ C2V_Cal 수정과 외부 실행이 필요하다. 명령행 래퍼로 py 디코더를 붙일 여지는 있다
- **C9. 논문의 비트폭 절감 이득은 없다**: V2C 폭은 th 레벨 집합이 정하고 (P,Q)와 무관하다. 사후확률에 해당하는 sum_t는 매 column마다 ch부터 다시 만드는 일시값이라 저장 폭이 없다. min1/min2 저장 폭은 RESET 승격 때문에 7을 담아야 하고 비교도 클리핑 전 값으로 하므로 줄지 않는다. 논문 전제(내부 폭이 입력 폭보다 넓다)는 이 시스템(채널 0~31, edge 3-bit)에서 뒤집혀 있다
- **C10. 판정 절차**
  - ㉮ 준비: `config_target.json`에 H-matrix, LLR 파일, 채널 슬롯 세 개를 채운다. 64프레임 예비 실행으로 무클립 FER이 0.1~0.5에 오는 E를 찾는다 (실측은 E 390에서 9.8e-3, 500에서 1.0). `max_frame_errors`를 `max_frames` 이상으로 두어 모든 쌍이 같은 프레임을 돈다
  - ㉯ 실패 갈래 확인: 무클립 실패 프레임의 dv별 오류 궤적(`bit_err_by_dv`)을 본다. 특정 dv에 동결돼 있으면 클리핑 스캔으로 답할 수 없다
  - ㉰ 개입 여지 지표 셋: min1 = 7 비율((5,7)용), min1 ≥ 5 비율((3,7) (3,5) (2,3)의 P 쪽), min2 = 7 비율((3,5) (2,3)의 Q 쪽). `_c2v_reconstruct` 재정의로 수집하고 프레임별로 들고 있다가 실패 프레임만 선별한다
  - ㉱ 사후 스캔: (7,7) (5,7) (3,7) (3,5) (2,3). (2,3)은 L을 edge 상한 7로 읽은 논문 가이드(P = L/4, Q = L/2)다. dv×P 반전 불능 표(flip_check.py)로 (5,7)은 정보 구간 어느 dv도 굳지 않고, (3,7)과 (3,5)는 dv4 3 row와 dv3 16 row, (2,3)은 dv11 5, dv4 22, dv3 28 row가 굳으므로 결과 해석에 참고한다. 같은 프레임에서 한쪽만 성공한 수로 판정한다
  - ㉲ 양성이면 결합형(002의 격차 임계 T = 2)과 구간별 (P,Q)로 확장한다. 음성이면 C8 ㉯의 py 국소 재탐색으로 넘어가고, 거기서도 음성이면 종료, 양성이면 외부 재최적화를 검토한다

## 001 문서에서 발견한 어긋남 (고칠 문서)

- ㉮ 반전 가능 조건 식: README 지표 계획 4행과 결론 ㉮의 `Q + (dv-1)×P`는 전제 없는 중간값이다. 굳은 열의 반전 불능 판정에는 dv×P가 맞고 (001 사망 관측 4건 중 3건 적중, 1건 동률), 절대 상한 dv×Q는 관측을 하나도 맞히지 못한다. README 두 곳과 실험로그 인사이트 ㉯를 dv×P로 통일한다
- ㉯ README 비율 복원 환경 결과표의 열 이름 (8,11)과 스캔 명령의 8,15가 다르다
- ㉰ `config_target.json`의 채널 슬롯 [200, 300]은 예시 부호용인데 README 준비된 실험 표와 파일 `_desc`는 "두 개만 채우면"이라 적는다
- ㉱ 동점: 본체는 sum_t ≤ 0에서 반전하므로 반전 불능은 extrinsic 상한 < ch다. 실험로그의 "(4,8)은 16 동률로 사실상 사망"은 동점을 사망으로 센 것이다

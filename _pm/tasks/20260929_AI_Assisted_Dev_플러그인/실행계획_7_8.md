# AI_Assisted_Dev 플러그인 실행 계획 (7단계 배포, 8단계 소개 페이지)

> 작성: 2026-09-30
> 설계: 9절 7번(evals 정비와 배포)과 8번(소개 페이지, 10절), 판정요청 물음 1의 답(개인 GitHub 비공개)

## 7단계: 배포

- ㉮ 저장소 루트 `.claude-plugin/marketplace.json`: 이름 `ai-assisted-dev`, 플러그인 하나(`source: ./plugin`, 0.1.0). `claude plugin validate --strict .`으로 검사
- ㉯ 루트 README: 설치(마켓플레이스 등록과 설치, 개발 중 `--plugin-dir`), 처음 쓰는 법 4단계, 스킬 17개 표, 에이전트와 자동 실행, 겹치는 플러그인 끄는 법, 폴더, 개발 명령
- ㉰ `plugin/README.md`: 배포 폴더만 받은 사람을 위한 짧은 안내
- ㉱ 검사 사례 정비: 13건 (1단계 2, 2단계 3, 3단계 1, 4단계 2, 5단계 1, 6단계 1 + 앞서 쓴 것). `claude plugin eval`이 열리면 돌린다
- ㉲ 판단: 회사 GitHub 반영과 태그(`claude plugin tag`)는 사용자 결정거리로 마지막 판정요청에 올린다

## 8단계: 소개 페이지

- ㉮ `docs/intro.html` (html이 정본). html_guide.md 규격: 정적, 상대 링크만, 외부 자원 없음, css 변수와 어두운 모드, 사이드바와 오른쪽 차례, 휴대폰 폭 대응
- ㉯ 구성: 무엇인가(카드 4), 빠른 시작(다섯 단계), 흐름(단계 상자 6), 프로파일 표, 스킬 17개(갈래별 접힘과 카드), 에이전트와 자동 실행 표, 작업 관리 카드, 자주 묻는 것(접힘 5)
- ㉰ 문장: 꾸미는 말과 감탄 없이 하는 일로. 줄글 대신 요소
- ㉱ 확인: Chrome 헤드리스 스크린샷으로 화면 확인, 깨진 링크 검사(render_dashboard.check_links는 dashboard/ 안만 보므로 intro.html의 링크는 손으로 확인)

# llr_tables.txt 템플릿
# 사용법: 이 파일을 llr_tables.txt로 복사하고 각 섹션의 값을 원본(HW 팀) 테이블 값으로 채운 뒤
#         실행 파일과 같은 디렉토리에 둔다. 파일이 없으면 코드에 내장된 기본 테이블이 사용된다.
#
# 포맷:
#   - '#'으로 시작하는 줄은 주석 (섹션 헤더 앞에서만 허용)
#   - 섹션마다 "이름 rows cols" 한 줄 + rows*cols개의 정수 (공백/줄바꿈 구분, 행 우선 순서)
#   - 섹션 순서 고정: CH_HD, CH_2SD, CH_3SD, TH_HD, TH_2SD, TH_3SD
#   - rows/cols는 빌드의 common.h 상수와 일치해야 함 (불일치 시 로드 실패 후 기본 테이블 사용)
#
# 3bit 빌드 (기본, __4_BIT_LLR__ / __AUTO_LLR_OPT__ 미정의):
#   CH_HD  63 4    (PRIME_HD_LLR_TABLE_NUM_ROW × PRIME_LLR_TABLE_NUM_DEGREE*1)
#   CH_2SD 36 8    (... × NUM_DEGREE*2)
#   CH_3SD 66 16   (... × NUM_DEGREE*4)
#   TH_HD  63 12   (... × NUM_DEGREE*NUM_TH, NUM_TH=3)
#   TH_2SD 36 12
#   TH_3SD 66 12
#
# 인덱싱 의미 (Get_VNU_*_Adaptive와 동일):
#   행 = table_idx (cur_set_idx, decoding status 기반 세트 번호)
#   열 = dv_idx(0~3: DV2/DV3/DV4/MIDDV·MAXDV 구간) × 항목수(ch 개수 또는 th 개수)
#
# 주의: CH_HD/CH_2SD의 현재 코드 내장값은 decoder.cpp의 Ch_LLR_HD/Ch_LLR_2SD 초기화 리스트에 있음.
#       CH_3SD/TH_* 는 소스 손상으로 코드 내장값이 소실됨(기본 0) — 반드시 원본 값으로 채울 것.

CH_HD 63 4
# (여기에 63행 × 4열 값 붙여넣기)

CH_2SD 36 8
# (여기에 36행 × 8열 값 붙여넣기)

CH_3SD 66 16
# (여기에 66행 × 16열 값 붙여넣기)

TH_HD 63 12
# (여기에 63행 × 12열 값 붙여넣기)

TH_2SD 36 12
# (여기에 36행 × 12열 값 붙여넣기)

TH_3SD 66 12
# (여기에 66행 × 12열 값 붙여넣기)

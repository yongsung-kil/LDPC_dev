# 3-7. `rand_sel_ep()` identity 재초기화 → swap 역복원

| 항목 | 내용 |
|------|------|
| 상태 | **적용 완료** (일괄 진행) |
| 파일 | `ldpc_revised/random.cpp` |
| bit-exact | 보장 (전제 조건 하에서 — 아래 참조) |
| 위험 | 중간 |

## 왜 / 어떻게

부분 Fisher-Yates를 위해 매 프레임 len_noPS(수만) 크기의 identity 배열을 재초기화했지만, 실제 뒤섞이는 원소는 n_err_len(수십~수천)개뿐이다.

- 사용한 swap 인덱스를 `swap_hist`에 기록
- 다음 호출에서 **역순으로 되돌려**(swap은 자기 역원 — 역순 합성이 항등) identity를 복원 → 초기화 비용이 len_max → 2×n_err_len으로 축소
- 다른 배열/다른 len_max로 호출되면 안전하게 전체 재초기화 (static `last_arr`/`last_len` 가드)

난수 소비 횟수·순서(`xor_r25` 호출 시점)는 문자 그대로 동일 → 선택되는 에러 위치도 동일.

## 전제 조건 (중요)

**호출자는 반환된 err_position을 읽기만 해야 한다.** 외부에서 배열을 수정하면 다음 호출의 역복원이 identity가 아닌 상태에서 출발해 결과가 오염된다. 현재 호출부 4곳(ecc_top의 fixed-error 계열)은 전부 읽기만 함을 확인. **이후 코드 수정 시 이 전제를 지킬 것** (코드 주석으로 명시).

## 이식 앵커

부분 Fisher-Yates의 identity 초기화 루프 검색. 호출자들이 배열을 수정하지 않는지 전수 확인 후 적용. 확신이 없으면 이 항목은 건너뛰어도 됨 (이득: 프레임당 수만 회 쓰기 절감).

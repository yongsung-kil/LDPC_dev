# 3-9. SD 양자화 루프의 모드 분기 hoisting

| 항목 | 내용 |
|------|------|
| 상태 | **적용 완료** (일괄 진행) |
| 파일 | `ldpc_revised/ecc_top.cpp` |
| bit-exact | 보장 (출력 배열 값 동일) |
| 위험 | 낮음 |

## 왜 / 어떻게

`Make_Dec_Input_AWGN_Quantize()`가 bit마다 `init_n`(2SD/3SD/1.5SD) if-체인 + `Get_Mag_*()` 호출을 반복 — `init_n`은 루프 불변. 분기를 루프 밖으로 꺼내 모드별 전용 루프 4개(HD 포함)로 분리.

- 각 모드 루프의 연산은 기존과 동일 (Lq 계산 → HD 판정 → Get_Mag_*)
- 사용하지 않는 중간값 계산 제거: 1.5SD 루프의 `Lq_ini_m`(미사용), HD 모드의 Lq 계산 전체 — 출력 배열에 영향 없음
- 1.5SD의 `(hd + sd) % 2` → `& 1` (hd/sd ∈ {0,1})
- 추가 개선 여지(미적용): `Get_Mag_*`를 channel.h로 옮겨 인라인화 — 별도 번역 단위라 현재 인라인 불가. `/GL` 빌드 플래그로도 해결됨

## 이식 앵커

AWGN 양자화 함수의 bit당 모드 분기 검색. 모드별 루프로 분리할 때 각 모드의 연산을 문자 그대로 복사할 것.

# minsum_dual_clip

날짜: 2026-08-13 | 출처: ieee:9496601 (A Low Bit-Width LDPC Min-Sum Decoding Scheme
for NAND Flash, IEEE TCAD 2022) | 상태: 보류 (실물 파라미터 반입 후 재실험)

## 목적

CNU에서 min1은 상한 P로, min2는 상한 Q로 각각 클리핑(1 ≤ P ≤ Q)하면 진폭 성장이
늦어져 저비트폭 성능 손실이 완화된다는 논문 delta를 vanilla 대비 on/off로 확인한다.

## 바꾼 것

- 디코더: decoder.py의 MinSumDualClipDecoder, 재정의 함수: `_c2v_reconstruct`
  (C++ 대응: C2V_Cal). P, Q는 클래스 속성 CLIP_P, CLIP_Q로 전달
- 설정: config.json은 vanilla와 동일 조건 (seed 0, fixed_error [200, 300],
  frames_per_batch 64), label만 변경
- (P,Q) 스캔은 scan.py로 실행 (label을 dualclip_p{P}q{Q}로 바꿔 순차 실행)

- ㉮ **(7,7)이 vanilla와 수치 완전 일치**: 클리핑 무효과 조건에서 동등성이
  확인되어 구현이 검증됨
- ㉯ **모든 유효 클리핑에서 악화**: P가 작아질수록 단조 악화
- ㉰ **같은 P에서 Q를 키우면 일관되게 개선**: (3,3) 1.00 → (3,5) 9.38e-01 →

  이중 상한(P<Q)이 단일 상한(P=Q)보다 낫다는 논문의 구조 주장 자체는 방향이 재현됨

## 결론

보류. 악화의 원인은 토이 파라미터의 스케일 불일치로 규명됨: 채널 LLR 크기가 8인데
클리핑 후 반전 가능 조건이 ch ≤ P × dv로 줄어들어, P ≤ 3이면 dv=2 열(17개 base
column)은 채널 결정을 영원히 반전할 수 없다 (P=5부터 2×5=10 ≥ 8로 반전 가능,
실제로 (5,7)만 경미한 차이). 논문의 이득은 내부 진폭이 채널 LLR보다 충분히 크게
성장하는 저비트폭 대형 부호의 error floor 영역에서 발현되므로, 이 토이 조건
(ch=8, 상한 7)에서는 클리핑 여지 자체가 없다.

유효성 판단은 실물 H-matrix와 LLR 반입 후 재실험으로 넘긴다. 유효 시 실물 C++
이식 지점은 `decoder.cpp` `CNU_Update_New_Mag()`에 min1/min2 확정 직후 clip 2줄
(`M1m=min(M1m,P)`, `M2m=min(M2m,Q)`).

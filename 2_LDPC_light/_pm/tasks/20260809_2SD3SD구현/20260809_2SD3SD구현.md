# 2SD/3SD 디코딩 구현

- 등록: 2026-08-09
- 상태: 진행 중 (C++ SD 경로 분석 후 설계 확정)

## 목적

HD 전용인 디코더를 2SD(2-bit soft decision)/3SD(3-bit soft decision)까지 확장한다.
채널과 로더는 준비되어 있고 디코더 산술만 막혀 있다.

## 배경

- ㉮ 채널: rber의 2SD/3SD 출력(sd/cc 플래그)과 strong_error(2SD)는 구현 완료
- ㉯ 로더: LLR matrix의 2SD(ch 2개)/3SD(ch 4개) 모드를 파일명으로 판별해 읽음
- ㉰ 디코더: HD 전용 가드가 `decoder_main`에서 명시적 에러를 냄
- ㉱ 실물 2SD/3SD LLR_MATRIX는 저장소에 없음

## 확정 사항 (사용자 결정 2026-08-09)

- ㉮ **toy LLR_MATRIX 파일로 개발**하고 실물은 반입 시 교체한다 (HD와 같은 방식)
- ㉯ **균일 생성 모드도 2SD/3SD를 지원**한다. `internal_quantize.channel_llr`를
  region별 값(2SD 2개, 3SD 4개)으로 받는 설정 확장이 필요하다

## 설계 (분석 후 확정)

C++ SD 경로 분석 결과는 `cpp_sd_analysis.md` 참조. 확정할 항목:

- ㉮ region 정의와 파일 ch 열 인덱스 매핑 (sd/cc 플래그 조합 → ch 인덱스)
- ㉯ VN 판정 산술의 HD 대비 차이 (채널 항이 비트별 배열이 되는 것 외의 차이 유무)
- ㉰ SD Edge Clear와 restart 규칙
- ㉱ syndrome과 read bit 처리의 동일성
- ㉲ 균일 생성의 region별 ch 스키마 (channel_llr: 스칼라 또는 리스트)

## 수정 대상 파일 (예상)

| 파일 | 내용 |
|------|------|
| `LDPC_base/decoder.py` | HD 가드 해제, region 인덱스 보관, 채널 항을 비트별 배열로, SD Edge Clear 규칙 |
| `LDPC_base/run.py` | internal_quantize.channel_llr 리스트 허용(모드별 개수 검증), 2SD/3SD 모드 차단 해제 |

| `Input/LLR/` | toy 2SD/3SD 파일 (LLR_MATRIX_2SD_toy.txt, LLR_MATRIX_3SD_toy.txt) |
| `config.json`, `README.md`, `docs/차이.md` | 스키마와 서술 갱신 |
